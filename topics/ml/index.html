机器学习与LLM

机器学习与 LLM 正在改写量化研究的做法。这个专题收录 GBDT 回归预测、XGBoost 自定义目标函数、神经网络时序建模等经典实践，也记录把大模型用于因子挖掘、资讯解析与 Agent 交易的真实实验——包括它们在哪里有效、在哪里不可靠。

这是「机器学习与LLM」专题的判断长文：LLM 到底能不能做交易？不讲概念，只讲我们做过的三个实验、踩过的坑，和一个诚实的结论。

一句话结论

问题 我们的答案 站内入口
LLM 能直接下单赚钱吗 不能（至少现在不能） 三实验复盘
LLM 能做什么 研报解析、代码生成、因子想法 RD-Agent、Hermes 实测

一、三个实验（我们亲手做的）

LLM 能做交易吗？三个实验讲透原理是本站阅读量最高的实验文之一，结论先行：

  • 实验一：让 LLM 直接预测涨跌——在中证 1000 上，效果约等于随机。LLM 对数值的理解是" token 级"的，不是"数值级"的（BPE 把 123.45 切碎了，它看不到连续性）。
  • 实验二：让 LLM 写策略代码——这个反而 work。把需求描述清楚，它生成的回测框架可用，省的是"写样板代码"的时间。
  • 实验三：让 LLM 读研报提因子想法——部分 work。它能从研报里提炼出"可测试的假设"，但每个假设都要你自己去验证。

三个实验合起来就一句话：LLM 是优秀的研究助理，不是交易员。

二、传统 ML 地位：XGBoost 还能打

LLM 很热闹，但表格数据上，GBDT 系依然是性价比之王：

  • 为什么 XGBoost 总有竞争力——二阶泰勒展开 + 正则，这套数学在中小规模表格上很难被 beating
  • PCA + 小波 + XGBoost 读论文——特征工程 + GBDT 仍是论文里的主流配方
  • XGBoost 自定义目标函数——理解"二阶可导"的要求，才能自己写 objective

新手建议：先把 XGBoost 玩明白，再谈 LLM。连表格基线都打不过的 LLM 策略，不值得上实盘。

三、Agent 方向的真实进展

Agent（多智能体协作）是 2025-2026 最热的方向，我们跟了三条线：

  • 微软 RD-Agent——把"因子挖掘"拆成"假设-验证"循环的四个智能体（R&D Loop），是目前最像"量化研究员"的 Agent 框架，值得跑一遍它的 Factor Task
  • Hermes 实测——我们亲手装过、踩过坑：结论是"想法好、工程还早"，适合尝鲜不适合生产
  • Vibe Coding 做大项目——Agent 写代码的上限测试：结论是小步快走可以，一次性大需求不行

三条线合起来：Agent 今天最适合的角色是"不知疲倦的初级研究员"——给它明确的任务定义和验证标准，它能 24 小时跑假设；但方向判断和最终拍板，还得是人。

四、给不同人的建议

  • 刚入门：别追 LLM，先学 Numpy/Pandas 和 XGBoost。地基不牢，Agent 产出的东西你也验不动。
  • 有基础：跑一遍 RD-Agent 的 Factor Task，理解"假设-验证"循环怎么自动化。
  • 做研究：把 LLM 当"研报阅读器 + 代码助手"用，保留人工验证环节；关注点放在"怎么验证"，而不是"怎么生成"。

五、延伸阅读

  • LLM 能做交易吗？三个实验——必读，三实验全文
  • 微软 RD-Agent——Agent 做因子挖掘
  • Hermes 实测——Agent 工程现状
  • XGBoost 二阶信息与正则——表格之王的数学
  • PCA + 小波 + XGBoost——论文配方
  • 期权定价不用写代码——AI 写策略的另一面

一句话：LLM 改变了"怎么做研究"，但没有改变"什么是好的研究"。验证标准没变，只是执行变快了。
