## 第五段：深度展开——当 LLM 开始选股：回测年化 28% 背后的技术拆解与实盘争议（15:00 - 35:00）

### 15:00 - 17:00 LLM 选股不再是玄学
- **LLM-FADT 策略**：基于文本的 LLM 选股方法
- **回测结果（2017-2025）**：
  - 年化收益 **28.93%**
  - 相对中证 500 超额年化 **26.43%**
  - 夏普比率 **1.13**
  - 信息比率 **2.08**
- **核心方法**：
  - 用 LLM 读财报、新闻、研报等文本，生成选股信号
  - 不是关键词匹配，而是让 LLM 做推理判断（如"这家公司下季度盈利超预期概率多大"）
- **为什么比 BERT-based 策略更强**：
  - BERT 做的是"模式匹配"（关键词出现频率）
  - LLM 做的是"推理判断"（理解语义、因果、隐含信息）
- **关键前提**：这个回测是 Point-in-Time 的，即模型在回测的每个时间点只能看到当时已发布的信息，没有数据泄露

### 17:00 - 19:00 第一板块：方向预测革命——为什么涨跌方向比涨跌幅度更重要
- **论文**："Direction is More Important than Speed"
- **实证设计**：用随机森林、梯度提升树（GBT）等 ML 模型分别做两类预测
  - A 组：预测"明天涨多少"（数值回归）
  - B 组：预测"明天涨还是跌"（方向分类）
- **结果**：
  - B 组（方向预测）的综合效果显著优于 A 组
  - 方向策略更抗噪音——即使加入随机扰动，方向信号衰减更慢
  - 对下跌行情的识别力更强——在 A 股这种波动大的市场，"躲过大跌"比"精准抄底"更有价值
- **和传统技术指标的呼应**：
  - MACD 金叉死叉、RSI 超买超卖，本质都是方向判断工具
  - 但 ML 方法可以综合上百个因子做方向判断，且能捕捉非线性交互
- **策略设计启示**：
  - 不要追求预测"涨到 35.6 元"，追求预测"大概率会涨"
  - 方向信号 + 仓位管理（如 Kelly 准则）= 长期正期望
  - 方向预测的天然优势：对极端行情的尾部风险识别力更强

### 19:00 - 24:00 第二板块：从单模型到混合专家——市场状态的动态适配
- **核心问题**：为什么一个模型在牛市好用，在熊市就崩？
  - 答案：金融时序的**非平稳性**——统计特征随时间变化
  - 趋势市、震荡市、反转市的驱动逻辑完全不同，用一个模型拟合所有状态必然过拟合
- **MoEDRLPM（KDD 2026）——混合专家深度强化学习组合模型**
- **架构拆解**：
  - **时序注意力**：刻画单资产的时间依赖（如某股票过去 20 天的动量结构）
  - **空间注意力**：刻画资产间的横截面相关性（如科技股同涨同跌的联动效应）
  - **Mixture of Experts（MoE）**：多个"专家网络"并行，每个专家擅长一种市场状态
    - 专家 A：趋势跟踪（高动量延续）
    - 专家 B：均值回归（超买超卖回调）
    - 专家 C：波动率套利（高波动环境下的期权/期货策略）
  - **门控网络（Gating Network）**：根据当前市场状态自动分配各专家的权重
- **训练机制**：
  - 不是预先定义"现在是牛市"，而是让门控网络自己从数据中学习状态划分
  - 强化学习目标：最大化长期风险调整收益（考虑回撤惩罚）
- **对量化的意义**：
  - 终于有一个框架可以"让模型自己判断现在该用什么策略"
  - 避免了人工划分市场状态的主观性（如"突破 20 日均线就是趋势市"）

### 24:00 - 29:00 第三板块：推理链 + 强化学习——让 AI 像交易员一样思考
- **Trading-R1（2025）—— LLM 推理链 + 强化学习的两阶段框架**
- **阶段一：LLM 做可解释的市场预测**
  - 不是直接输出"买"或"卖"
  - 而是输出完整的推理链（Chain-of-Thought）：
    - "昨天美联储释放了鹰派信号 → 美元走强概率上升 → 新兴市场资金外流压力增大 → A 股北向资金可能缩减 → 回避外资重仓股"
  - 这个推理链是可读的、可审计的——风控部门可以检查 AI 的"思考过程"
- **阶段二：基于预测动态调仓**
  - 把 LLM 的推理结果编码为特征向量
  - 输入给强化学习策略网络，生成目标仓位
  - RL 目标函数：综合考虑收益、夏普比率、最大回撤
- **效果**：
  - 相比纯 RL 基准：收益提升约 **3 倍**
  - 夏普比率翻倍
  - 关键改进：可解释性——当策略亏损时，可以追溯是哪一步推理错了
- **为什么这比传统量化更强？**
  - 传统量化："因子 A 高 + 因子 B 低 → 买入"（黑箱）
  - Trading-R1："因为美联储鹰派 → 外资流出 → 减仓"（白箱推理）
  - 在监管趋严和机构客户要求可解释性的环境下，白箱策略有天然优势

### 29:00 - 33:00 第四板块：争议与陷阱——LLM 量化是真实突破还是回测幻觉？
- **争议 1：数据污染**
  - GPT/Claude 的训练数据包含到 2023-2024 年的金融信息
  - LLM 可能在回测中"记住"了某些历史事件的结局（如"2020 年 3 月新冠崩盘后 V 型反转"）
  - **解法**：Point-in-Time（PIT）回测 + 用训练时间截断的模型（如只训练到 2019 年的 LLM）
- **争议 2：回测过拟合**
  - 28.93% 的年化是在特定参数下跑出来的，参数调多了必然过拟合
  - **解法**：Walk-forward 优化（滚动窗口调参）+ 样本外验证（Out-of-Sample）
- **争议 3：市场结构变化**
  - LLM 选股在 2017-2022 效果好，但 2023 年后量化基金规模暴增，传统 Alpha 衰减
  - 当太多人用类似方法，Alpha 就变成 Beta
  - **解法**：持续迭代模型（如用最新财报数据微调）、引入另类数据（卫星图像、供应链数据）
- **争议 4：推理成本**
  - 用 GPT-4 级别的模型处理每只股票的财报，成本极高
  - **解法**：模型蒸馏（大模型教小模型）、批量推理、用 DeepSeek 等低成本模型替代
- **关键判断**：
  - LLM 量化不是"圣杯"，但也不是"骗局"
  - 它是一个**新的工具类别**——就像 2010 年的机器学习、2015 年的深度学习一样
  - 早期采用者可能有超额收益窗口期，但窗口会随竞争加剧而关闭

### 33:00 - 35:00 总结：LLM 量化的三个范式转移

**第一：从数值预测到方向预测**
- 放弃预测"涨多少"，专注预测"涨还是跌"
- 方向信号更稳健、更抗噪音、更适合仓位管理

**第二：从黑箱因子到白箱推理**
- 用 LLM 的推理链替代传统因子的隐式权重
- 策略可解释性成为竞争优势（监管要求 + 机构客户信任）

**第三：从单策略到动态专家**
- 一个模型打天下 → 多个专家网络自动切换
- 市场状态判断从人工规则 → 门控网络自主学习

**收尾判断**：
- LLM 不会取代量化研究员，但会重塑"研究员-模型-实盘"的协作方式
- 研究员的角色从"写因子代码"转向"设计推理框架、定义奖励函数、审核模型决策"
- 最终赚钱的仍然是那些既懂市场、又懂 AI 的混合型人才
- 对普通听众的 actionable 建议：不要急于实盘，先用免费工具（如 OpenRouter 上的模型）在模拟盘验证方向预测策略
