# 打破期权定价的"鸡生蛋"困局

## 康奈尔团队用AI+跳跃隐马尔可夫模型重构合成期权数据生成

> 作者：量化前沿观察 | 阅读时间：约12分钟

---

## 一、一个百年难题的最后一公里

想象一下：你要给一件商品定价，但定价需要的核心参数——市场对该商品的"情绪估值"——本身又来源于这件商品已经成交的价格。这就是期权定价领域一个长期存在的**循环依赖困局**（circular dependency）。

美式期权（American Option）允许持有者在到期前的任何时间行权，是全球金融市场最重要的衍生品之一。要给它定价，**隐含波动率**（Implied Volatility, IV）是不可或缺的输入。但隐含波动率本身，恰恰是从已交易的期权价格中反推出来的。

这就形成了一个"先有鸡还是先有蛋"的悖论：

```
要生成合成期权价格 → 需要隐含波动率作为输入
要获得隐含波动率 → 需要已有期权价格来反推
```

这个困局的后果是什么？它意味着做市商、风险管理者、量化交易团队在**生成合成期权数据**时，永远无法摆脱对真实市场数据的依赖。他们无法自由地生成"如果市场处于某种极端状态"的期权价格场景，无法为机器学习模型提供足够丰富的训练数据，也无法在全新的市场条件下回测对冲策略。

2026年5月13日，康奈尔大学Robert Frederick Smith化工与生物分子工程学院的Julia Sun、Zheyu Jin、Jiawei Zhang和Jeffrey D. Varner在arXiv上发表了一篇题为**《Synthetic American Option Pricing via Jump-HMM-Driven Heston Implied Volatility》**的论文，彻底打破了这一循环。

## 二、这篇论文的核心贡献：让波动率反客为主

传统上，隐含波动率是**输入**。这篇论文的核心思想是把隐含波动率变成**输出**——不是从市场中读取，而是从一个结构化的股票收益模型中自然涌现出来。

### 三阶段流水线

论文提出的框架是一个精密的**三阶段流水线**：

```
┌─────────────────────────────────────────────────────────┐
│              合成美式期权生成流水线                        │
├──────────┬──────────────────┬────────────────────────────┤
│ 阶段一   │ 阶段二           │ 阶段三                     │
│ JumpHMM  │ 修正Heston方差   │ CRR二项式树               │
│ 生成多   │ 过程：状态依赖   │ 定价：含提前行权          │
│ 资产价   │ 的均值回复目标   │ 的美式期权               │
│ 格路径   │ 产生IV路径       │                           │
├──────────┴──────────────────┴────────────────────────────┤
│ 结果：合成美式期权价格 + 隐含波动率曲面 + Greeks         │
└─────────────────────────────────────────────────────────┘
```

**阶段一：跳跃隐马尔可夫模型（JumpHMM）**

首先，模型将连续的超额增长率离散化为N个"市场状态"（通过拉普拉斯分布的分位数分箱实现）。股票价格在每个时间步处于某个隐藏状态，状态之间的转移由马尔可夫链控制。

关键创新在于引入了**泊松跳跃机制**：在每个时间步，以概率ε触发一个跳跃，强制链进入尾部状态（极端牛市或熊市）。这产生了真实金融数据中观察到的**波动率聚集**现象——极端行情往往持续一段时间。

> 📊 **图示建议**：一张展示JumpHMM状态随时间演化的示意图，显示正常状态与尾部状态的切换，以及对应的波动率变化。

多资产方面，模型通过**Student-t Copula**引入资产间的尾部依赖——当多个资产同时处于极端状态时，联合尾部事件的发生频率远高于高斯Copula的预测。这正是2008年金融危机中"万物皆跌"现象的数学刻画。

**阶段二：修正Heston随机方差过程**

经典的Heston模型（1993）描述资产回报的瞬时方差v遵循均值回复平方根过程：

```
dv = κ(θ - v)dt + σv√v dWv
```

其中θ是长期方差目标，κ是回复速度，σv是波动率的波动率。

这篇论文的核心创新在于将θ从一个常数变成了**时变的、状态依赖的函数**：

```
θ(i,t) = θi,st · (1+γ·Mt) · ψ(DTEt, K/St, ei,t, ei,t^peer)
```

这个公式中包含了四个层次的信息：
1. **θi,st**：每个股票在每个HMM状态下有独立的基础波动率水平
2. **γ·Mt**：市场情绪指数——当超过一定比例的股票同时处于尾部状态时，整体市场波动率自动上升
3. **ψ函数**：微笑曲线和期限结构的形状控制
4. **ei,t**和**ei,t^peer**：公司自身和同行业其他公司的财报日期信息

最重要的是，模型采用了**平衡初始化**策略：每个（股票、行权价、到期日）三元组的初始方差直接设定为其均值回复目标v₀ = θ(t=0)。这意味着微笑曲线、偏斜和期限结构**无需任何外部校准**，自动从模型结构中产生。

**阶段三：CRR二项式树定价**

有了隐含波动率后，最后一环是用Cox-Ross-Rubinstein二项式树（CRR tree）计算美式期权价格，包含每个节点上的提前行权检查。

研究团队发现了一个精巧的工程设计：在生成前向场景时，他们改用**Leisen-Reimer (LR) 树**而不是CRR树。LR树的独特优势在于行权价K始终精准落在树节点上，这消除了计算Greeks（Δ、Γ、Vega）时由于K在节点间"跳动"而产生的混叠效应。

## 三、对量化金融的意义：为什么这很重要？

### 1. 合成数据饥荒的终结

深度学习改变了从图像识别到自然语言处理的所有领域，但在量化金融中，它始终面临一个根本性瓶颈：**数据不够**。

真实市场数据是有限的（每天只有一个收盘价，每年约252个交易日），而且市场 regime 变化缓慢。这篇论文的框架允许研究人员**按需生成无限量的合成期权数据**，覆盖各种市场状态（包括从未发生过的极端场景），且保证数据在经济学上的一致性。

### 2. Deep Hedging的助推器

Buehler等人（2019）提出的"深度对冲"（Deep Hedging）框架用神经网络替代传统Black-Scholes Delta对冲，但它需要大量高质量的期权价格数据进行训练。这篇论文恰好提供了这个能力——生成的合成数据包含完整的路径条件隐含波动率、有限差分Greeks和空头权利金损益。

### 3. 风险管理的新范式

论文展示了在31只股票、6个行业板块、15个交易日、234,549条记录的期权梯级上校准模型，并前向模拟了空头权利金场景。这意味着风险管理者可以生成**"如果明天市场暴跌20%且波动率翻倍"**这样的条件场景，并精确量化其对期权组合的影响。

### 4. 内生崩盘保护溢价

论文报告了一个有趣的现象：模型生成的合成期权价格包含了**内生的崩盘保护溢价**（endogenous crash-protection premium）。当市场情绪指数M上升时，所有合约的波动率自动升高，因此虚值看跌期权（OTM puts）自动变得更贵——这与实际市场中观察到的"恐慌溢价"完全一致。

## 四、该领域五位顶级专家及其核心观点

要理解这篇论文的学术坐标，我们需要先认识量化金融领域五位最具影响力的思想者：

### 1. Marcos López de Prado（马科斯·洛佩斯·德普拉多）

- **身份**：阿布扎比投资局（ADIA）全球量化研发主管、康奈尔大学教授
- **核心观点**：机器学习应该从根本上改变金融的实证方法。他提出了"金融机器学习"学科，发明了层次风险平价（HRP）、元标记（Meta-labeling）、三重障碍标记法等一系列被行业广泛采用的技术。他的著作《Advances in Financial Machine Learning》是量化ML领域的"圣经"。
- **与他论文的关系**：López de Prado是康奈尔大学工程学院的教授（与论文作者Varner同在康奈尔），他的工作为论文提供了方法论基础。论文中神经代理模型替代解析形式的思路，与López de Prado倡导的"用数据驱动方法替代参数化假设"一脉相承。

### 2. Jim Gatheral（吉姆·加瑟拉尔）

- **身份**：Baruch学院数学系杰出教授（Presidential Professor）
- **核心观点**：波动率曲面是可以被精确参数化的。他提出的SVI（随机波动率启发式）参数化方法和著作《The Volatility Surface: A Practitioner's Guide》是整个衍生品定价领域的奠基之作。近年来他专注"粗糙波动率"（rough volatility）研究，发现波动率过程具有分形维数的特性。
- **与他论文的关系**：论文第2.4节直接引用了Gatheral的SVI模型作为基准，并将其解析形式作为神经代理模型的起点。论文的ψ函数本质上是对SVI在（ln τ, ln m）空间的泛化。同时，Gatheral 2025年与Pommergård Lind合著的"NN de-Americanization"论文与本文形成了有趣的互补——Gatheral用NN从美式期权反推欧式价格，而这篇论文则从第一性原理生成美式期权价格。

### 3. Sebastian Jaimungal（塞巴斯蒂安·贾蒙加尔）

- **身份**：多伦多大学统计科学系主任、Fields研究所Fellow
- **核心观点**：随机控制与强化学习的融合是量化交易的下一个前沿。他在算法交易、最优执行、均值场博弈、商品市场等领域做出了开创性贡献。他的著作《Algorithmic and High-Frequency Trading》是该领域的标准教材。
- **与他论文的关系**：Jaimungal的工作为论文中的随机控制元素提供了理论框架。论文中前向模拟的场景分析与Jaimungal在最优执行和风险感知强化学习方面的工作形成技术呼应。论文生成的合成期权Greeks（Δ、Γ、Vega）正是Jaimungal框架中所需的输入。

### 4. Jean-Philippe Bouchaud（让-菲利普·布绍）

- **身份**：CFM创始人、法国科学院院士
- **核心观点**：金融市场本质上是一个复杂系统，传统的随机游走模型无法捕捉市场的真实行为。他开创了"统计金融物理学"（Econophysics），强调肥尾、自相关衰减、波动率聚集等"程式化事实"（Stylized Facts）应该成为任何市场模型的检验标准。
- **与他论文的关系**：论文第2.1节直接引用Cont（2001）提出的程式化事实——肥尾、线性自相关可忽略、波动率聚集——作为JumpHMM的设计目标。论文明确验证了合成数据在Kolmogorov-Smirnov检验和Anderson-Darling检验上的通过率。这正是Bouchaud风格的"先有事实，后有模型"的实证方法。

### 5. Andrey Itkin（安德烈·伊特金）

- **身份**：纽约大学Tandon工程学院研究员、American Options定价专家
- **核心观点**：美式期权的半解析定价可以通过广义积分变换（GIT）方法实现，无需依赖蒙特卡洛或有限差分网格。他在时间非齐次跳跃扩散模型中的工作为美式期权定价提供了新的思路。
- **与他论文的关系**：Itkin的工作代表了美式期权定价的"精确路径"，而本文则选择了"生成路径"。两者的对比很有意思：Itkin追求在给定模型参数下的精确解析解；本文追求在给定收益路径下的端到端合成数据生成。两者的方法论互补，服务于不同的实际需求。

## 五、这篇论文的创新点深度剖析

### 创新一：打破循环依赖（核心突破）

这是论文最大的贡献。所有现有框架要么从市场拿IV（循环依赖），要么生成价格路径但没有一致的IV曲面。这篇论文让IV成为结构模型的**内生输出**。

```
传统方法： 市场期权价格 → 反推IV → 作为输入定价新期权（闭环）
本文方法： 价格路径 → JumpHMM → Heston过程 → IV自然涌现 → 定价（开环）
```

### 创新二：状态依赖的Heston均值回复目标

标准Heston模型的θ是常数。本文的θ是HMM状态、到期时间、价内外程度、市场情绪、财报日历的函数。这意味着当HMM跳入尾部状态时，θ自动上升，IV整体抬升——不需要额外的波动率冲击模块。

### 创新三：层次化的形状函数表示

论文设计了一个精妙的**表示层次**：

```
解析5参数形式 → 全局共享神经代理 → 板块特定神经代理 → 个股级神经代理
    (最节省)                                      (最灵活)
```

每个层次都是在容量和泛化之间的权衡。在目前的数据量下，板块特定代理提供了最佳偏差-方差权衡。未来随着个股数据量增长，可以直接无损升级到个股级网络。

### 创新四：财报事件感知机制

论文发现时间外推误差的主要来源是**预定企业事件**（财报发布）。为此设计了两个日历特征：
- **e**：距目标股票最近财报日的天数（带符号，截断至±30天）
- **e^peer**：距同行业其他股票最近财报日的最小绝对值

这个机制让网络学会了财报前的IV扩张和行业内溢出效应。

### 创新五：全开源Julia实现

整个框架以**开源Julia包**的形式发布（MIT许可证），包含完整的校准、验证和前向模拟代码。这意味着全球的研究者和从业者可以立即复现、验证和改进这项工作。

## 七、局限性与未来方向

任何开创性工作都有其边界。论文自己也坦诚地讨论了几个局限：

1. **财报事件的稀疏性**：虽然日历特征恢复了部分外推误差，但仍有大量不可预测的"意外事件"（如诉讼、监管变动）无法被模型捕获。

2. **高频动态缺失**：模型在日频尺度上运行，无法捕捉盘中波动率曲面的变化。

3. **板块同质性假设**：板块内形状共享假设减少了参数，但像科技板块内部（AAPL vs. NVDA）的差异可能被压缩。

4. **市场情绪指标的简化**：Mt仅是尾部状态占比的简单平均，现实中市场情绪是更复杂的多维构造。

未来方向包括：纳入高频数据、扩展至其他资产类别（如固定收益、外汇）、与深度强化学习框架的端到端集成。

## 八、结语

量化金融的演进史，本质上是一部**"如何用更少的假设做更多的事情"**的历史。Black-Scholes用了5个假设（包括最受诟病的常数波动率），Heston放松了常数波动率但引入了更多参数，López de Prado的ML方法用数据替代了参数假设，Gatheral的SVI用解析形式精确刻画了波动率曲面。

这篇康奈尔团队的论文站在了所有这些巨人的肩膀上，做了一件巧妙的事：它不再试图更精确地拟合波动率，而是**让波动率从市场微观结构中自然生长出来**。

对于量化从业者而言，这意味着一个新的工具箱——一个可以自由生成任意市场状态下合成期权数据的工具箱。对于机器学习社区而言，这意味着一个丰富的"期权数据游乐场"。对于风险管理而言，这意味着更真实的压力测试场景。

当我们回过头来看这个"鸡生蛋"困局时，答案其实是朴素而优雅的：**不要从蛋里找鸡，而是理解鸡为什么下蛋。**
