## 大富翁量化框架

这个产品我们是从 2019 年开始做的，到 2022 年底基本完成 2.0。当时的目标就是既要开源，又要满足量化私募自用。我们最核心的规则有这样几条：

1. 必须能够存储分钟线
2. 只使用 Python 技术栈
3. 严格遵守市场交易规则，杜绝自己欺骗自己

存储分钟线最大的难度，就是你存进去之后，怎么能保证高性能地把它读取出来？我们粗略估算一下，从 2005 年到 2025 年底，分钟线的数据大概是 36 亿条左右。在 2019 年开发这个项目时，怎么存储这么大量的数据？ 市场当时其实没有一个很好的答案。但大家已经认识到股票数据、行情数据的存储，它是一个时间序列数据，它有自己的读写规律。如果按照这些读写规律来设计数据库，性能会高一些。所以当时业内实际上刚刚开始认识到，应该有一种时间序列数据库来存储。我们当时是比较早地使用了时间序列数据库，influxdb，在当时确实是比较好地解决了这个问题。

我们当时有一个测试，就是遍历 A 股全部股票数据。具体来说，每只股票取 250 分钟的记录。这样遍历下来，大概需要 2 分钟。考虑到我们并不是要做一个高频交易引擎，这个性能加上适度的优化，完全可以满足你在尾盘集合竞价时，对市场进行扫描并完成交易的需求。

做到这件事，真正的挑战在于只使用 Python 技术栈

我们为什么要设定这个目标呢？ 主要是方便中小私募和独立交易员。它们不太可能拥有一个强大的基础设施团队，所以如果我们使用的技术栈过于复杂，这样独立交易员和中小私募就难以掌握。但是 Python 确实存在性能问题，所以这对我们编写代码的要求就非常高，我们充分发挥 Python 胶水语言的特性，凡是对性能有要求的地方，我们都尽可能地使用numpy,数据库原生的能力来解决这些问题。

在当时我们觉得比较难的一个问题，就是如何快速地从分众线合成，五分钟、十五分钟、三十分钟，直到日线、周线.在实盘交易时，你的日线行情、30分钟线行情等，在每一分钟线甚至每一个 tick 更新之后，它的指标都会变.如何能在接到数据的 1 秒到 2 秒之内，就完成所有的数据更新

最后我们是通过把这件工作挪到 Redis，然后通过服务器脚本来实现快速更新的.

3. 关于严格遵守市场交易规则

我们发现，很多开源的量化交易框架，是从国外其他流行的框架迁移过来的。由于市场制度不同，在移植过程中，这部分特性并没有得到很好的反映，特别是没有得到强制。

比方说 T+1、涨跌、涨跌停板限制等。这样会导致一个问题：有的策略会有意或者无意地突破这些交易规则，从而得到更好看的数据。

但是我们当时想，做量化交易，如果自己欺骗自己，没有任何意义。必须从框架本身要牢牢地限制住自己的策略研究员搞一些自期期人的东西的可能性.因此， 我们的量化交易框架在架构设计上与传统的回测框架非常不同。这个框架实际上是模拟了真实交易的情况，也就是说我们的回测引擎实际上是一个仿真的交易柜台

在这个框架下，无论研究员的策略怎么写，交易柜台这边都给你限制死了。所以你不可能突破 T+1 的限制，也不可能突破涨跌停板的限制来买卖股票. 另外，这样做的另一个好处是，因为我们做的是一个仿真的交易柜台，所以要求策略这边一定要采用动态前复权。也就是说，你策略交易的价格不是那种后复权的价格，而是回到某年某月某日。当天用市场真实的交易价格来进行交易。因为我们仿真柜台这边读到的加载数据全部是原始的数据。所以它的仿真度，对实盘的还原度非常高。

我觉得这是我们架构上最大的一个特点。这个特点还带来一个额外的好处，就是使得我们从策略的回撤到实盘交易，变得非常简单

在大富翁量化框架中写回测策略时，买卖信号并不会由策略框架来处理，而是发送到网关处理的。而这个交易网关就相当于是一个实盘的仿真网关。所以从回测切换到实盘，只需要切换一个 URL就可以了。

即使有一些真实的交易网关，并没有提供http 服务。那我们也只需要在前面加一个能够接收 HTTP 请求的gateway 进行协议转换就可以了，不需要改动策略一个字。

## 第1条：什么是量化金融，散户能不能做量化？

第一，什么是量化交易？量化交易在李斯纳兰的《打开量化交易投资的黑箱》里面，我觉得他说的很好。用我的语言来理解的话，就是你有一个可建模的策略，这个策略是在通过历史数据得到验证的。然后你以程序化的方式来执行这个策略，这样就是量化交易

这三点核心，第一点就是要可建模。可建模的含义就是，你可以用程式化的语言或者数学模型把你的策略讲清楚。那么在遇到同等的条件的时候，它触发的结果一定是一样的

第二点就是你的策略，它是要经过大量的历史数据的回测，这样才通过了回测，你才会保留下来，成为一个有效的策略，
第三，从执行层面来讲，这个过程它也是程式化的去执行，不会因为你的主观的恐惧或者冒进，去贸然启动交易，或者说不敢进行交易

散户能不能做量化？其实散户的定义呢，应该是说你的资金量，所以你的资金量能不能做量化，当然最终是看你能不能开户。当然现在开户的门槛其实也不高，所以理论上散户肯定是可以做量化，另外可能大家会有这个疑问，是总觉得散户在资讯、在数据、在智力各方面都赶不上机构，所以天然具有劣势，这方面其实也是很大的一个误解，散户你可以聪明的像香农一样，就是信息论的发明者、诺贝尔奖获得者。那他们其实也是散户。那如果你自己不具备创新的能力、识别市场交易模式的能力，那你就算混进了机构，你去负责一个产品，那大概率也会一败涂地。

那么其实我之前在知乎上写过一篇文章，来讲散户做量化，它其实是有优势的。这个最大的优势就在于，就是散户从回测到执行，到实盘执行，这个过程失真会很小。因为如果你是资金量很大，那么你回测的时候，你会按信号发出来的那个价格去执行买入或者卖出。就算你加上一点滑点，这也会比市场真实的反馈要乐观很多。另外一种可能就是，你如果坚持是要在这个价位不加滑点进行买入的话，那么你能够成交的交易量就会很少，那么相当相，就相当于说你研发了，辛辛苦苦研发了一个策略，但最终你的资金投不进去，没办法进入到实盘，

那我们刚刚讲过，量化的本质的特征就是要能够进行回测。你如果连回测都没有了，你还做什么量化？

所以说，不是散户能不能做量化，散户其实更适合做量化。但是具体到每一个人，那你自己能不能做量化？你有没有那种探索的精神？有没有它必要的知识结构？你愿不愿意去学习？ 比如最近有一位同学来咨询我们的课程，他就反复在问量化对学历的要求是不是很高？是不是我这个学历就没有办法进入这个行业。我们当时就跟他说了很多例子，包括我之前的研究员，有学历好的，也有学历一般的，并没有单纯因为学历就来卡他们。我现在的学员中也有一些“双非”的，在我们培训之后，他们也顺利进入了量化私募。但是无论跟他怎么讲，他老是反复跟我们纠结这件事儿。所以我又跟他举了一个例子，我是从 IBM 出来的，当时我们有一个副总裁叫吴世宏，他的学历才中专。

所以我就跟他讲，你看，就算是中专，你也能够进 IBM，但是是不是所有的中专生都能去 IBM？

所以不是散户能不能做量化，而是具体到我们每一个人里，能不能做量化，这是需要你自己去回答的问题。

那也可能会有人说，那你怎么去破解资讯上的优势？其实我个人觉得，你比人家早一点知道某个消息，不见得就能够获得某种优势。内幕交易之所以诱人，只是因为人们相信它是捷径。其实内幕交易它都不见得是百战百胜的，因为市场的力量无比的强大，所以对散户来讲，就是那种短期交易，今天买明天卖的这种交易，其实有量价数据就够了。我再举一个例子，做高频交易的，他们凭的是什么？只有量价数据，然后有的是拼规则、拼速度。

## 第2条：主观 vs. 量化？区别与联系，他们 alpha 的来源是什么，相同吗？

那么按照前面李斯纳兰的关于量化的定义，主观跟量化交易之间最大的区别就是你能不能够通过模型把你的交易策略给固定下来，在相同的条件下会触发出相同的判断

但是如果我们要从产生阿尔法的这种原理上面来区分量化和主观的话，主观和量化还有很大的不同，那像巴菲特和芒格，对他们而言，就是是典型的主观价值投资。巴菲特在他们的就是股东大会和股东来信中，就把他们主观的这一面表现得非常淋漓尽致。比如他在一次股东信中说，投一家公司，他要去看这家公司的文化，CEO 的品格如何，这些是完全没有办法量化的事情。也就是说，他实际上看的是这家公司的执行团队，他们是否具有企业家精神，那么这一点是完全无法量化的，甚至说你要去识别另外一个人是否具有企业家精神，这件事情本身它靠的也是信仰，靠的是价值观认同，靠的是文化和背景趋同，也正是这样，巴菲特才错过了好多科技股的投资，因为当科技股大爆发的时候，巴菲特和芒格他们年事已高，对这种新的科技，他们去把握它确实会感到力不从心。所以他们只有当他的真实的现金流产生了多年以后，就像苹果那样，他们才会开始投资。

但是主观投资者可以使用量化的方法，这样有可能把把资产曲线做得更平稳一点。这个是没有问题的。但量化的永远抢不了主观投资者的饭碗。这就相当于现在 AI 出来了之后，我们相当一部分的人会被 AI 抢走饭碗，但是人类并不会跟 AI 分享权力，AI 想要夺得这种权力，它也必须拿命来换，AI 也不太可能出现像人类 idol 那样的角色，就是出现一个超级的 AI 明星，所以AI 可以比人类强很多。但有一些人类的活，AI 永远抢不走。我想这个差别也可以类比到于主观和量化上。

我觉得业界在谈论主观阿尔法的时候，大家很可能会说我通过财报去发现了哪一家公司很有潜力。这个你其实是在做量化能做的活，这个价值已经不大，其实主观投资者你要去看财报，那你已经晚了一步。通过财报你可能是会发现公司治理上存在一些什么问题，但是你说要能够去发现投资机会，我觉得这个已经晚了。当然过去几十年，大家做的都是资产定价，对吧？追求的就是发现被错误定价，市场低效会导致的错误定价。但是量化会把这部分给补齐，但是量化很难决定说，在 2023 年以前去投一家叫 Anthropic 的公司，或者说去投一家叫 OpenAI 的公司，因为对量化来讲，它没有这个数据，也因此就无法做这个投资。

主观阿尔法还有一个量化很难替代的点，就是在黑天鹅事件中去补仓。比如像但斌总他们在09年前后，白酒塑化剂事件出来以后，对茅台进行加仓。我觉得这些是量化难以抓到的点。因为量化模型的训练需要大量数据，但这些极端事件天生是少数样本，所以很难做到既被量化模型吸收训练，又不产生过拟合。

从少数事件中学习和归纳，再进行演绎，这恰恰是人类的优势。人类的大脑有着**惊人的通过直觉发现规律**的能力。

## 第4条：量化金融适合什么样的散户？名校？高学历？竞赛金牌？

做量化交易需要什么样的背景？名校、高学历、竞赛金牌，觉得这些是充分条件，但不是必要条件

量化的本身是一个商业路径非常短的商业模式，所以它有一点相当于每一个量化独立量化人都相当于一个创业者。那作为创业者来讲，能够成功的，其实是什么样的人都有，在过去，量化可能它需要一点点专业知识，因为我们讲过量化必须要会编程。但是现在这个门槛也是在逐渐降低，所以我觉得最重要的可能就是黄仁勋讲过的一个词，叫 resilience，就是韧劲。因为你做量化，特别是我们接触到很多策略研究员，经常会为挖不出来新的因子，找不到好的策略而感到很苦劳、很焦虑。那实际上，这个也是很多创业者或成功人士的一个常态，因为你本来选择的就是确定性很低、风险很高的一个事，所以在这个过程当中感到很焦虑，会有挫败，很正常。那么要能够对抗这种焦虑和挫败感，最重要的就是 resilience

成功的散户量化交易者其实很多。梁文锋早期就是独立量化交易员，他的学历虽然也不错，但是作为应届毕业生来讲，他这个级别的毕业生我们国家每一年大概有 10 万人左右，所以，梁文锋总当然是我国的优秀人才了，但是如果你要拿学历去筛选的话，那可能这样优秀的人才也会被筛选掉。

然后我们说量化交易的从业者，他也不见得就是一定要通过策略去做投资，就跟做 AI 的人一样，并不是所有人都是做大模型的。那我们今天看到就是做 A 景应用的人也有成功的，做路由中转的人也有很成功的。所以在量化交易这个领域，那我们除了直接做量化策略的人之外，还有做量化开发的，甚至做这种销售的，渠道都很多

其实量化也并不是一个非常特殊的行业，它跟其他任何行业一样，你的机会可能会大于你的努力，能够抓住机会的人都是非常具有韧劲的人，而不是只能打顺风仗，不能打逆风仗的人

## 第5条：观察我周围的人：小资金（<100万），不专业，做交易 > 做投资。我就是一个普通人，需要具备哪些基础条件

做量化的资金门槛大概是 10 万起就够了。但是如果你要投身量化交易，之前没有相关的专业背景，那么你一定要具有这样的特质。第一个，爱学习，对新的东西感兴趣，很好奇。第二，非常有韧劲，做事呢不会是只凭一时的热情。第三呢，有比较强的逻辑推理能力。就是如果你完全不是这个专业的，那么你之前也没有接触过编程，甚至本来是纯文科。但是你如果考过公的话，那行测那门分数比较高，那我觉得基本上也是可以的。只不过说，看你离量化的要求距离的远近，你可能要给自己的准备的时间就有长有短

编程、数学、金融，哪个是最低门槛？我自己觉得可能编程的门槛更大一点，这个是挡住你能不能入门的一个关键。如果说你无论是手写还是借助 AI，你没有办法跑通一个小的功能，那么你就肯定永远被挡在量化的门槛之外。在门槛之外的人，你是没有是没有晋级的可能的

至于说数学，当然这块数学越好，那么你越是有可能独立做出创新。这里我举一个简单的例子，比如如果你要对 k 线图做浪型分析的话，首先是要找到历史 k 线上的最高点和最低点，这些最高点和最低点的连线，就是一段段波浪。如果你完全没有数学的知识，这件事也可以做，就是去找第三方库中，已经实现好的 API，自己来调用就可以了。比如在 scipy 当中，有好几个类似于 find_peaks 这样的 API 可以帮你找顶点。但是这些方法是用以数字信号处理的，它在决定某个点是否是顶点时，需要你传入一些参数，比如该点与周围的点比，高多少，并且传入的是一个绝对值。所以，你直接使用的话，就会找不准顶点，因为这个绝对距离差，在不同的品种上，不同的时间段和不同的周期级别上，都不一样。所以，应该有一个自适应的参数。那如何确定这个自适应的参数呢？如果你对基础的统计学知识比较熟悉，你可能就会想到，那我是不是可以把它当成一个正太分布，去找95%分位数点？实际上，这几乎是这个问题的最佳答案。

所以，从这个例子来看，你掌握的数学知识越多，你的方法就会越多，策略就可能更精准。

但是我们也不要过于放大数学的作用。毕竟金融它不是一个纯粹的数学的游戏，它甚至都不是一个纯粹理性的东西。所以你没有办法完全用一两个数学公式去套它，而且我们常常讲一句话叫做，高端的食材往往只需要最简单的烹饪方法，这件事情应用到赚钱这件事情上，其实道理是一样的，爱因斯坦是这个世界上最聪明的人。他研究的那些东西，彻底的解放了我们这个星球的生产力。他个人的财富不光是跟他释放的这些巨大的财富完全不能比，就跟他同时代的富翁也是没有办法相比的。那那些没有他聪明的人，他们是怎么赚到钱的呢？

如果只有少量的时间投入，应该先学什么？这个其实如果你连编程都不会，那你首先是要学编程，或者说学通过 AI 来进行编程，如果你已经精通编程了，那么你也很可能的就是要去做实战。因为你作为一个独立量化交易人来讲，你不要搞那些玄而又玄的数学理论。因为很多那些数学的东西，它是为复杂的金融衍生品设计的。他们设计出复杂的金融衍生品，然后呢利用这些东西再来进行套利。这个我觉得普通人没有必要去参与这些东西

## AI为量化带来哪些变化

这一轮的 AI 发展，可以定义为技术的革命。他一定会重塑各行各业，所以对 量化 也会带来非常多的变化。

首先，我们说量化一定是关于程序的这一轮 AI 革命，最成功的就是 AI 写程序，已经被证明比大多数人要强，这样会使得越来越多的人，只要你有强烈的热情，就可以进入量化这个行业，门槛被削平了。

Agent，我觉得更多的是增强了主观投资者的能力。比方说，人在收集资料信息上面拼不过计算机，那 Agent 就可以帮我们 24 小时不间断地持续跟进一些事件消息，并且进行一个粗略的分析，包括帮我们去盯盘等等。目前的 AI 都是生成模型。在生成时，它是按一定概率进行的生成。这个概率被称为 temperature。所以从这一点来讲，通过 Agent 来做交易，并不满足我们对量化交易前面所定义的条件，即在同样的条件下触发同样的决策。所以我觉得 Agent 目前还不可能取代量化交易。

建议主观投资者早点入手，类似于 Trading Agents 这样的工具。trading agents，实际上是从去年这个时间前后就被开发出来的。我们当时也进行了介绍。 

但是当时如果你用不了海外的那些顶级大模型，它的价值其实不是那么高。但是大家知道，今年初 AI 大模型基本上可以认为又出现了一个代际的跨越，不管是海外的顶尖大模型，还是国内的顶尖大模型，现在都是非常能打的状态。所以，Agent对事件的分析就有了价值。

主观交易者最大的二难悖论是：你必须坚持你自己，才能成功。但你越坚持自己，就越看不见真实客观的消息。所以通过 Trading Agent 可以很大程度上解决这个问题。你可能不会相信你身边的人提给你的反对意见，但是很少有人会不敬畏那个全知全能的 AI 模型。

## 面向散户做量化是否存在创业机会

几年前，我们对这件事的看法肯定会有比较大的争议。因为量化确实存在一个编程的门槛，而很多人会被这个门槛挡住。

我们又看到像 Big Count 这样的公司，他们当初借鉴了低代码编程的一些想法，然后做了一些类似于，通过 UI 拖拽就可以生成一套策略并进行回测的工具。当然，这样又降低了一些门槛。但是，要使用这样一套框架，你还是要了解很多跟编程、跟金融相关的一些知识。而且，稍微复杂一点的算法，有时候可能就比较难，通过一些简单 UI 元素的组合，把它给定制出来。

所以，我们来看中量化还是有一些门槛。有门槛就说明你的用户基数不够高。

但是我们知道，面向散户，特别是中国散户这样一个群体，他们的付费意愿没有那么高，所以很难支撑起一个大的市场。

由于 AI 的加入，编程这件事比之前变得容易了很多。给大家举一个例子，像 Claude, GPT这样的大模型，都有自己的专属 Harness. 大家可能常常听说过,Anthropic 在编程方面这么强，一半是 Claude 大模型厉害，另外一半是 Claude Code 这套 harness 很厉害，配合得很好.

因为每一个大模型都有自己的特性，理论上会有一个专属于它的 harness，是能够最大程度地把大模型的优势发挥出来的。

但是DeepSeek v4 发布之后，DeepSeek 家是没有做 Harness 的。他们只有模型。

于是有一个国外的小哥，出了一款 DeepSeek UI，把这个事儿给解决了。那么这个小哥是什么人呢？他的专业是音乐指挥。后面还自己修了一个法律专业。他根本就不是 IT 界的人，正是一名不 IT 界的业余码农，给专业码农写了一个编程工具。

所以，尽管现在编程这件事仍然具有一定的专业性，但门槛确实大大降低了，所以量化目前的受众，比之前可以说多了 10 倍甚至上百倍。场子热闹了，自然就会有机会。
