## /01 开场

宽粉：欢迎收听本期的《量化好声音》，我是宽粉。今天我们的选题是：大语言模型和 Agent 进入量化交易领域快两年了，到底走到了哪一步？

之所以会有这个疑问，是因为过去一年我们看到了太多两极分化的现象。一方面，GitHub 上只要跟“多智能体交易”沾边的开源项目，关注度都非常高，比如大家熟悉的 TradingAgents，Star 数已经超过了 10 万；但另一方面，真正把系统拉到公开市场上去跑实盘或者实时模拟的，结果往往不太好看。

所以，听众朋友们也是一方面跃跃欲试，不希望自己在时代浪潮中被落下；另一方面又不知道大模型、Agent 在量化交易中到底该怎么用。所以，我们今天就来聊聊这件事。

Aaron：对，我们考察了6、7个相关联的项目，今天就跟大家聊一聊， 业界是怎么用 llm 和 Agent来做交易的，有哪些流派，疗效如何，有没有实战检验的例子。

宽粉：说到实战检验啊，去年底，海外有一个叫 nof1.ai 的网站做了一场实验，对多个 AI Agent 的实盘交易进行全网直播，当时引起了很大的轰动。但是九个月过去了，现在这个网站目前已经是门前冷落鞍马稀了。

原因很现实，参与交易的 Agent 里，成绩最好的一个，夏普比<率|LI4>也只有 0.019，这个表现甚至不如普通散户。也就是说，在第一阶段的公开测试里，直接让通用大模型下场做交易，效果是不及格的。

但就在最近，我们关注到了韩国开发者开源的一个项目，叫 PRISM-INSIGHT。这是可以直接在美股和韩国股市上做实盘交易的项目。作者还做了一个网站，让这个项目每天做交易，把结果提交到网站上进行直播。现在已经进行到第390天了。从最近6个月的情况来看，它是大幅跑赢了韩国综合指数 KOSPI 的。KOSPI 6个月来是下跌10.36%，而它的模拟盘依然保持了12.97%的盈利。此外，它还有一个小资金的实盘，该实盘目前是保持了20.23%的盈利。

所以，我们今天的主角就是这个 PRISM-INSIGHT 项目。

Aaron: 对，我们会深入探讨 PRISM-INSIGHT 的构建原理，然后也会和其他的几个项目做一个横向的对比。最后，我们还会讲一下在这个项目里如果自己想上手，我们需要做些什么、如何部署。

宽粉：对，Aaron, 你看，除了 PRISM-INSIGHT 之外，其实我们在 Github 上还可以找到很多所谓的 Vibe trading， 也就是通过 Agent 来做交易的系统。除了刚刚提到的 nof1.ai 之外，还有 trading-agents，它现在有超过10万个 star了；还有 easy-stock, 超过 1600 个 star，这是一个适用于 A 股的AI投研系统；Vibe-Research，github 上的星数超过 2800 了。

那我们今天为何要以 PRISM-INSIGHT 为主来介绍 Vibe trading? 它有哪些亮点？

Aaron：对， PRISM-INSIGHT 呢，它是有这样一些亮点的。一是前面你也讲过了，它实盘已超过390天了，取得了比较稳健的成绩；二是它是一个能直接投入实盘的投研系统，其它的系统，有的主要目标还停留在辅助人进行研究上，并没有完成端到端的投资；三是它自己的投研体系是对 威廉·欧奈尔 的CAN SLIM 成长股动量交易体系的一个改造。CAN SLIM 体系比较有名，也比较成功，所以本身就这一点来说，也值得介绍。

最后，PRISM-INSIGHT 并不是完全的 Vibe trading，它把适合 vibe 的地方交给 llm， 把需要严格遵守规则的地方交给 python 程序。

所以，对于任何想用 AI 辅助投资或者做量化开发的人来说，去拆解它的架构设计、看看它是怎么掉进坑里又怎么改规则的，能省去自己摸索的大量试错成本。

## 架构拆解

宽粉：好，那我们就先从它的系统结构拆起。PRISM 是如何运作的？

Aaron: PRISM 是一个 Python 的单体程序加多个 Agent，形成了一个四段闭环的流水线。这个流水线，就是筛选 > 分析 > 交易 > 反馈。

在筛选阶段，它通过 yfinance 来取得数据，然后设置了 6 条触发条件。这六个条件分别是：

1. 早盘的量增榜，要求成交量放大超过 30%
2. 第二个条件是：早盘要有跳空动量；跳空幅度要大于 1%；形态上要收阳线。
3. 第三个条件是市值资金的集中度，这是一个打分的指标，最终是按股票的排序来进行筛选。
4. 第四条是盘中，要求涨幅在 3% 到 15%，并且要收阳。
5. 第五是衡量尾盘的强度，它要求：收盘位置大于阈值；要放量；涨幅要在 0% 到 15% 之间。
6. 第六条是放量横盘的特征：量增率大于 50%，涨跌幅的绝对值小于 5%，并且要站上 20 日均线

宽粉: 感觉这都是淘股吧里所谓高手常常讲的那些特征啊。果然高端的策略往往只要最朴素的因子。

Aaron: 对，那筛选阶段呢，对应的是欧奈尔 CAN SLIM 体系中的 S和 L 字母，即供需关系分析和领导者分析。

分析阶段，由多个 llm Agent 构成。这一层有6个 Agent,分别是量价分析，投资者分析，公司基本面分析，公司概览与同业对比，新闻分析和指数+宏观检索。

宽粉: 在我们网站上，发表过一篇文章，叫 llm 能做交易吗，三个实验讲透原理。我记得那篇文章中，你分析过 llm 是不能从量价中提取信号的。那prism 这里让 agent 去做了量价分析，这两者相冲突吗？

Aaron: 但是 PRISM 并没有直接去做量价分析，它实际上做的是基于量价的趋势分析。

比方说，它会提取 5 日、20 日、110 日、200 日的均线，看支撑阻力，看股价是否突破了这些均线。它基于一些工具的调用和自己的推理，现在实际上能够保证在这些地方尽量少出错。另外我注意到就是在它的框架当中它会自己去计算RSI（相对强弱指标）、MACD 和布林带。所以这些技术指标仍然是被量化分析师广泛认可的。

接下来应该是介绍投资者分析，对吧

宽粉: 对，这是 CAN SLIM 中，字母 I 对应的 Investor 部分。

Aaron: 这个分析是做什么呢？ 它看的是机构、外资和个人的逐日买卖这些数据，然后分析出来的结论呢，就是三类资金谁在买，资金和价格的背离和共振。在我们的博客文章中介绍过，股市是由不同风格的资金共同作用的结果。机构资金，他们体量大，转身慢，因此他们一般持股的周期是以季度来计算的。

而散户资金呢，他们交易速度快，属于快进快出。如果你对价格走势进行频谱分析或者小波分析，就会发现有不同周期的资金在里面进行博弈。

宽粉: 对，我记得有这么一篇文章，你使用的是傅里叶分析，几乎是精准地还原了上证20年来的走势。

Aaron: 接下来就是 company_status、company_overview和news_analysis这三个分析师，它们大致对应了CAN SLIM 体系中的最近季度营收增长，年度增长等基本面分析——这是对应的字母 C+A； 新产品、新业务、新管理层、近期大事件，以及当日事件催化剂——这是对应的字母 N。

宽粉: 最后一个就是市场风格分析，也就是大盘方向分析，对应字母 M?

Aaron: 正是。

宽粉: 刚刚的比较偏选股策略。那我问一个技术问题。我注意到在 PRISM 项目的介绍中，写到他们有 13个 Agent，但你刚刚只介绍了6个？

Aaron: 应该是项目初期，确实存在过 13个 Agent。刚刚介绍的是分析阶段的6个 Agent。在第三步，也就是交易阶段，它还有一个策略汇总 Agent， 把前面 6 份报告整合成一份投资策略。

在第四步，进入交易环节。买入决策 Agent根据成文的评分表打 1 到 10 分，并写出建仓后的加仓情景；卖出决策 Agent负责监控持仓的止损和止盈。

主要是这四步，就构成了一个交易闭环。不过，为了帮助用户理解系统的运作，它还有两块盘后工作。一个是沟通模块，负责把长报告浓缩成 400 字的电报消息并翻译成多国语言推送；另一个是日志与记忆模块，在股票平仓后做复盘总结，提炼经验供下一次买入参考。

所以现在涉及交易的主要是8个 Agent，其它做辅助工作的还有几个。

宽粉：听完这个流程，我首先有一个关于多 Agent 架构的根本问题。PRISM 为何要做成多 Agent 架构？ 一个投研系统，究竟使用多少个 Agent 才好？

Aaron：多 Agent 架构相比单 Agent 架构来说，可以有以下好处。

在工程实践里，把任务拆给多个 Agent，最核心的价值就是**「视角隔离」与「工具数据的专有化绑定」**。我们可以做一个思想实验，如果只用一个全能的 Agent，把刚突破新高的漂亮 K 线图、题材炒作的新闻、还有一份负债率很高的财务报表同时塞给它，会发生什么？大语言模型天生有“连贯性偏见”，它非常擅长编造一个自圆其说的故事。当它看到股价在暴涨、新闻在吹捧时，它很容易在同一个上下文里自我说服，把高负债解释成“为了扩张的必要投入”，从而忽略掉财务风险。

但是当你拆成 6 个独立的 Agent 时：首先，它们的**角色设定（System Prompt）和立场是完全隔离的**。财务 Agent 的提示词要求它只看估值、盈利质量和资产负债表，它看不到市场情绪有多狂热，因此能保持冷酷的审计视角；而新闻 Agent 绑定的是 Perplexity 搜索和 Firecrawl 网页抓取工具，专门负责去挖催化的真实性；资金流 Agent 绑定的是韩国投资证券（KIS）的席位数据。

其次，每个 Agent 先在自己的专业维度内形成独立的判断和证据切片，最后再交由策略汇总 Agent 和买入决策 Agent 去碰撞、权衡。再加上不同环节可以配置不同成本的模型——比如基础信息整理用中等规模的模型，最终买卖裁决用推理能力最强的模型，日常摘要和复盘用轻量级模型——这样既保证了分析视角的多样性与客观性，又控制住了整体的运行成本。

宽粉：这就讲清楚了。那如果我们把视野放宽一点，把这个项目和另外几个项目，比如 Trading Agents, easy-stock 和 Vibe-Research 放在一起对比，它们在 Agent 的设计理念上有什么不同？

Aaron：这四个项目恰好代表了把 LLM 引入投资领域的四种不同设计思路：

先看 **TradingAgents**。它的设计重心在于**「观点对抗与辩论机制」**。它同样先设了基本面、情绪、新闻、技术四个分析师 Agent，但在分析师之后，它专门设计了一个研究员团队，包含一个看多研究员（Bullish Researcher）和一个看空研究员（Bearish Researcher）。

这两个 Agent 会拿着前面四个分析师提供的材料，进行多轮结构化的辩论（Debate）。这个机制非常有价值，因为金融市场永远存在正反两方面的证据，通过显式的多空辩论，可以把单边思维隐藏的风险点逼出来，最后再交给交易员和风控 Agent 做决定。

不过，TradingAgents 的定位是一个研究框架，用来做单点或阶段性的实验，它没有内置实盘券商接口，也没有提供长期连续运行的公开业绩账本。

再看 **easy-stock** 和 **Vibe-Research**。这两个项目的共同特点是定位非常务实——它们不做全自动无人交易，而是做**「本地优先（Local-First）的投研工作台」**，把决策权留在人手里，用 Agent 来解决数据收集和证据核验的效率问题。

但在具体实现上，两者的侧重点又完全不同：
**easy-stock** 针对的是 A 股特有的短线、题材与连板结构。它的核心不是让大模型直接看原始 K 线，而是先用 Go 语言后端把连板梯队、晋级率、题材强度、情绪周期算成结构化的数据模型，再让 Agent 去解读。它还有一个很实用的功能，是每天定时用浏览器桥接去抓取雪球、淘股吧上多位市场作者的复盘文章，让 AI 提炼出当天的观点共识、主要分歧以及次日需要验证的条件；在持仓管理上，它会按逻辑、结构、风险、策略匹配度四个维度给用户的持仓打分，并提供调仓前后的同次对比评估。

宽粉: 所以这是打板爱好者必须要去研究的一个项目了。

Aaron: 对，那 **Vibe-Research** 则是偏重基本面与多维数据的投研工作台，接入了 A 股、港股、美股的 168 个数据端点。它在工程设计上最值得借鉴的一点，是极度严格的**「数字出处审计」**。在它的六阶段个股研究和日常问答里，程序会强制核对 AI 输出的每一个数字——这个数字必须在用户消息、当前抓到的接口数据、网页或本地研报里找到出处，或者是明确列出的算式算出来的；这就避免了最让人头疼的“数据幻觉”问题。

最后回到 **PRISM-INSIGHT**。它和前面三个最大的区别，在于它试图跑通从“信息感知、分析研判”一直到“实盘自动下单、盘后复盘反馈”的全自动闭环。

宽粉：说到这儿，我想追问一个关于“盘后复盘反馈”的原理问题。

我在看 PRISM 文档的时候，看到了两个机制：一个是它在生成电报摘要时用的 `Evaluator-Optimizer Loop`（评估-优化循环），另一个是它在平仓后写交易日志、提炼直觉（Intuitions）并反馈给下一次买入决策的机制。

我觉得这是大家会比较关心的一个问题，就是我们有一手的优质数据，希望反馈给 Agent 以提升它的智能，但自己又没有重新训练大模型的条件和能力。那有可能在不改变大模型权重的情况下，仅仅靠这种循环、或者靠不断积累交易的正反例样本，去提升整个系统的预测和交易能力吗？

Aaron：这是一个非常核心的AI工程问题。不训练模型权重，靠积累历史交易的正反例闭环来提升系统决策能力 —— 不仅在原理上完全可行，而且正是目前学术界和工业界最前沿的研究方向，通常被称为**上下文强化学习**或者**「语言空间强化学习」**。

宽粉：不改模型参数，怎么实现类似强化学习的效果？

Aaron：我们可以对比一下。传统的强化学习，是在每一局游戏或每一笔交易结束后，根据盈亏奖励，通过反向传播去修改神经网络的权重参数，让模型下次在同样的状态下做出更好的动作。

而在大模型应用里，我们改不动千亿参数的权重，但大模型有一个强大的能力叫**上下文学习**。如果我们把每一笔交易的“当时买入选股的依据、市场状态、最终盈亏结果、以及事后复盘找出的原因”结构化地保存下来，经过归纳压缩，变成一套持续更新的“经验规则库”。当下一次遇到类似的股票时，系统自动把最相关的正反例经验检索出来，放进买入决策的提示词里。从数学上看，虽然模型的参数没变，但模型做决策的**条件概率分布**已经改变了。这相当于我们不是在“参数空间”里做梯度下降，而是在**“自然语言提示词空间”**里做策略迭代。

而且我昨天专门看了一下 PRISM 仓库最近一周的提交记录，作者在刚刚做了一次非常有意思的升级（提交的标题叫 `rebuild BUY intuitions from big movers vs lookalikes`），意思是从相似大行情中重构交易直觉。

以前它的记忆系统只是简单地对亏损交易写检讨书；但作者发现这样不够，于是改成了一种**正反例对照提取法**：系统把历史上真正走出大行情的牛股（Big Movers，也就是正样本），和那些买入时各项指标、突破形态看起来一模一样、结果却止损失败的“假突破股票”（Lookalikes，也就是机器学习里说的困难负样本 Hard Negatives）放在一起，让模型专门去对比这两组样本在基本面、催化或量价细节上到底有什么差异，从而提炼出分辨真假突破的“直觉（Intuitions）”。

作者还在代码里专门写了一个统计函数，来持续对比“参考了历史经验并调整了分数的买入交易”和“没有参考历史经验的交易”，看前者的实际胜率和平均收益率到底有没有跑赢后者。如果某条提炼出来的直觉在后续验证中胜率低于 30%，或者超过 90 天没有被验证，清理脚本就会自动把它停用（Deactivate）。

所以，这套“正反例对比提炼 + 实际胜率检验 + 劣质经验淘汰”的机制，在原理上已经非常接近一套完整的非参数化强化学习系统了。


## 审视欧奈尔体系——60 年代的方法今天还管用吗？

宽粉：讲完架构，我们进入到第二个核心议题：PRISM 所依托的交易哲学——**威廉·欧奈尔（William O'Neil）的 CAN SLIM 体系**。

我们前面已拆解了这套体系在 PRISM 中是如何实现的。但是，我必须先抛出一个很多人心里的怀疑。

欧奈尔是在 1960 年代发明这套体系的。一套投资体系，跨越数十年，也为很多人所熟悉了，那么，在今天它还会有效吗？

我举个例子。在 CAN SLIM 体系中，同时使用了基本面信息和量价信息。但这两类信息在更新周期上是不一样的。基本面信息，它是每季度更新两到三次；而量价数据，每天、每秒都在更新。

在 60 年代，信息传播靠报纸和邮寄财报，市场消化一条基本面信息可能要花几个星期。但到了今天，借助互联网的强时效性、高频算力和 AI，数据分析的周期已经毫不费力地压缩到了日内甚至秒级；而相比之下，公司基本面信息的更新，哪怕不按季度，至少也是按月为单位才更新的。这是两个完全不在一个数量级上的时间周期。

现在任何一条基本面信息一旦发布，往往一到两个交易日就完全反映在股价上了，剩下的几十个交易日里，基本面根本没有新东西。那在这种市场环境下， CAN SLIM 体系中的基本面信息到底还有多大用处？每天都在跳动的量价信息，难道不能完全反映基本面吗？

Aaron：你提的这个问题，可以说是所有做量化和做交易的人都绕不开的“市场有效性”之问。如果信息在一两天内就定价完毕，60 年代的欧奈尔体系在今天是不是早就变成古董了？

我的看法是，**信息传播的速度确实变成了秒级，但大资金改变持仓的物理过程，依然是以“周”和“月”为单位的；基本面在今天的作用，已经不是用来做“日内抢跑”，而是用来给量价异动做“真伪证伪”和“持仓周期定性”。**

我们可以从两个层面来拆解你刚才说的周期错配问题：

第一，**为什么一两个交易日消化不完基本面？** 这就涉及到CAN SLIM 中为什么要做投资者分析了。因为大型机构（公募、养老金、长线外资）受限于风控合规和市场流动性，哪怕今晚财报大超预期，它们也不可能在第二天集合竞价把几百亿的仓位一口气买满，否则会把股价直接买崩。第一、二个交易日的跳空大涨，往往是游资、量化事件驱动资金和先知先觉的买方打出来的“点火信号”；而在随后的两三个月里，随着产业逻辑被不断验证、上下游订单跟进，大型机构在回调中分批建仓，才构成了完整的主升浪。
第二，**量价信息能不能完全替代基本面？不能，因为量价极易出现“同形异质（Lookalikes）”。**
在某一个交易日的早盘，一只纯靠小作文炒作、主营业务连年亏损的概念股，和一只刚刚拿下海外大单、行业迎来产能紧缺的成长股，它们在分时图和日 K 线上表现出来的“放量突破、资金净流入”可以是完全一模一样的。如果只看量价，系统根本分不清这是“主升浪的起点”还是“游资拉高出货的诱多”。
在没有财报发布的平时那几十个交易日里，基本面扮演的是一个**“慢变量过滤器”**和**“持仓信心锚”**。只有确认了基本面的底色是真的，当股价在突破后第 5 天遭遇大盘回调、缩量下跌 4% 的时候，系统才敢判断这是正常洗盘并继续持有，而不是惊慌失措地割肉。

宽粉：明白，也就是说量价是快变量，负责提供触发时机；基本面是慢变量，负责过滤假信号和决定你能拿多久。

既然 CAN SLIM 并没有过时，那我还得问一个问题，CAN SLIM 这套打法，为什么值得用 Agents 再做一遍？
那我们接下来就严格核实一下欧奈尔的 **CAN SLIM** 这七个字母。很多文章对这七个字母的解释往往夹杂着个人演绎。如果我们回到欧奈尔的原著《笑傲股市》和《投资者商业日报》（IBD）的官方定义，这七个字母到底代表什么？更重要的是，在这七个字母里，有哪些是过去几十年传统量化早就写烂了的，又有哪些是因为过去的技术限制无法定量实现、直到今天有了大语言模型才真正能够自动化的？

Aaron：问题非常好！ 其实，投资如山岳般古老，但技术一直在不断创新。技术的创新就给我们带来了把老戏法重新演绎一遍的契机。

在欧奈尔的 CAN SLIM 体系中， 前两个字母 C 和 A， 也就是 Current Quarterly Earnings，当季每股收益与营收 和Annual Earnings Growth，年度盈利持续增长，在过去几十年里，是**最容易被传统量化定量的**。任何一个人写几行 SQL 查一下财务数据库就能筛出来。今天大模型在 C 和 A 上面能做的增量比较有限，主要是去读财报附注，帮我们剔除掉那些靠卖地、卖子公司或者汇兑损益凑出来的“假增长”，以及对比数字有没有超过买方预期。

接下来看第三个字母 **N**。在欧奈尔的原著里，N 的官方完整定义是：**New Products, New Management, New Highs off Properly Formed Bases，也就是新产品、新服务、新管理层、行业新变局，以及股价从良好的整理形态中走出并创出新高。

请注意，欧奈尔把“基本面之新”和“价格之新”浓缩在了同一个字母 N 里。他说过一句很著名的话：在他研究了跨越几十年的大牛股后发现，95% 的超级牛股在启动时，背后都有某种重大的“新变化”作为引擎，同时伴随股价突破平台创出新高。这个也是做 A 股的朋友们常常会有感受的，就是股还是那些股，但是每一年都会有新的题材。

Aaron: 现在我们想想：在过去几十年的传统量化里，宽客们是怎么写 N 这个因子的？

宽粉：代码没法知道公司有没有颠覆性新产品，所以只能写“股价创 52 周新高”？

Aaron：完全正确！过去的量化策略在复刻 CAN SLIM 时，全部把 N 简化成了单一的价格指标——比如当前收盘价接近或创出 52 周新高。结果就是把 N 最核心的灵魂——“因为基本面出现了新产品、新技术、新管理层或行业供需新变局，从而推动股价创新高”——给阉割掉了！

而今天，**这恰恰是最适合大语言模型发挥价值的第一个核心突破口**。在 PRISM 里，当量价脚本发现某只股票突破异动后，它的 `News Analyst` 和 `Company Overview` Agent 会立刻调用搜索和爬虫工具，去读公司最新的公告、新闻稿和行业报道，用自然语言理解能力去核实：这次异动背后，到底有没有实质性的新产品发布、大额新订单落地或者行业政策催化？如果没有，仅仅是股价莫名其妙拉升，Buy Agent 在打分时就会直接压低分数。

我们再往下看第四个字母 **S（Supply and Demand，供求关系）**，指的是流通股本大小适中、有股票回购，且在关键突破日成交量比平时放大 50% 以上。这也是传统量价代码很容易算清楚的。

但到了第五个字母 **L（Leader or Laggard，领涨股还是落后股）**，传统量化又遇到了第二个天花板。

欧奈尔强调，要在行业里买真正的领头羊（Leader），绝不买因为便宜而跟风补涨的落后股（Laggard）。为了量化这件事，欧奈尔当年发明了著名的 RS 指标（Relative Price Strength，相对价格强度，从 1 到 99 打分），看这只股票过去一年的涨幅跑赢了全市场百分之多少的股票。

宽粉: 这就是 A 股的龙头战法哈。

Aaron: 但是，你要怎样才能发现真龙？ **“价格涨得快”就等于“产业真龙头”吗？** 不一定。在概念炒作初期，一只边缘蹭概念的小票可能连拉几个涨停，RS 分数冲到 99，但它在产业链里毫无议价权，潮水一退就原形毕露。

过去计算机读不懂产业链结构，只能用 RS 价格动量来近似代替 L。而现在，**这是大模型带来的第二个核心突破口**：像 PRISM 里的行业分析 Agent，或者刚才提到的 Vibe-Research、easy-stock 里的产业地图模块，大模型可以通过阅读研报和公司主营构成，直接梳理出“在 HBM 内存或者光模块产业链里，谁掌握核心产能、谁的毛利率最高、谁在给核心大厂供货”。把**“定性的产业竞争地位（Business Leader）”**和**“定量的相对价格强度（Price Leader）”**结合起来，L 这个字母才算是真正被完整实现了。

最后两个字母，**I（Institutional Sponsorship，机构认同度）** 和 **M（Market Direction，大盘方向）**，这基本上还是传统量化的用武之地，就不展开讲了。

宽粉：这一段梳理太有价值了！听众朋友们完全可以顺着这个思路去举一反三：过去几十年投资界有很多经典的投资框架——不管是欧奈尔的 CAN SLIM、彼得·林奇的成长股分类、还是巴菲特的护城河理论——以前我们做量化时，只能挑里面有现成财务指标和量价数据的部分来写代码，那些真正决定成败的定性维度（比如 N 里的新业务变局、L 里的产业链真实地位）全都被迫丢掉了。而今天大语言模型的出现，本质上是让我们第一次有工具，去把那些被传统量化遗弃的“定性拼图”重新捡回来，装进自动化系统里。

Aaron：没错。而且很有意思的是，当 PRISM 的作者真正把这套体系装进系统、在韩国和美国市场跑了一年多之后，他还发现了一个更现实的问题——即便选股端靠 AI 补齐了 N 和 L，如果照搬欧奈尔 60 年代写的某些机械持有规则，在今天的市场里照样会亏钱。

宽粉：这在开发者的更新里讲过，卖飞大牛股的教训。

Aaron：对。这也正好回应了你刚才说的“时代变了，市场节奏变了”。统计显示，在入场后 60 个交易日内涨幅超过 30% 的韩国牛股里，这些股票最高涨幅的中位数达到了 +60%，但系统实际平仓拿到的利润中位数只有 **+2%**！绝大多数大牛股，刚涨了一点就被移动止损或卖出 Agent 给提前洗出去了。

为了解决“拿不住牛股”的问题，作者决定去测试欧奈尔体系里最著名的**「8 周持有规则（8-Week Hold Rule）」**——欧奈尔原著规定，如果一只股票从突破点算起，在 1 到 3 周内快速上涨满 20%，就具有成为大牛股的潜质，应该至少持有 8 周，或者一直拿到跌破 50 日均线。

但作者没有直接拍脑袋上线这条规则，而是利用项目里的回放测试台账，拿系统过去真实筛选出的候选股和交易记录做了一次验证。结果发现：**如果原封不动地照搬欧奈尔的“涨满 20% 就死拿到 50 日均线”，韩股的单笔累加收益反而倒退了 43 个百分点，美股也倒退了约 40 个百分点！**

宽粉：为什么欧奈尔当年的黄金法则，放到今天的市场上会失效得这么厉害？

Aaron：因为今天市场的短线波动结构跟 60 年代完全不同了。作者拆分数据后发现：**凡是在买入后 1 到 3 个交易日内就急涨 20% 的股票，在今天的市场里，绝大多数是受短期消息刺激的情绪脉冲，而不是真正的机构趋势股。** 这种股票在两三天内暴涨 20% 后，股价离下方的 50 日均线非常遥远；如果你机械地执行“不破 50 日均线不卖”，接下来几天资金一撤退，股价快速回落，等你碰到 50 日均线时，20% 的浮盈早就回吐干净甚至变成亏损了。
相反，回放数据表明，真正能走出长线的领涨股，是在买入后 **4 到 15 个交易日**内，经过换手消化、稳步推升达到 +20%，并且当时股价没有过度偏离 50 日均线的股票。
所以，PRISM 在今年 10 月初上线的新规则里，对欧奈尔的教条做了明确的修正：
1. **改良领涨股持有（Leader Hold）**：1 到 3 天急涨 20% 的股票，不享受豁免，依然按常规的利润保护止损及时落袋；只有在 4 到 15 个交易日内涨满 20%、且未过度偏离 50 日线的股票，才进入“领涨股持有模式”，在最长 40 个交易日内，只要收盘不破 50 日均线且不破首次买入成本价，就一直持有。
2. **用 AI 情景加仓替代固定阶梯加仓**：放弃死板的涨 2%、涨 4% 机械加仓，改为首仓按波动率买一个槽位的 30% 到 80%，由 AI 写出 2 到 4 个加仓触发剧本（比如突破或回调企稳），由代码在价格高于成本且满足条件时执行金字塔加仓。
3. **证伪并放弃无效规则**：比如欧奈尔门徒后来常说的“口袋支点（Pocket Pivot）”放量触发器、还有按 ATR 波动率设止损，在 PRISM 自己的历史数据回放里都被证明没有正收益甚至更差，于是被作者明确写进废止台账里放弃掉了。

宽粉：你看，这个过程就非常有说服力。它告诉我们，即便是把经典大师的体系交给 AI 去自动化，也不能搞教条主义。一方面要用大模型去补齐过去无法定量的 `N` 和 `L`；另一方面，面对今天秒级定价和量化博弈的市场微观结构，又必须用真实交易台账去修正 60 年代的老参数。

Aaron: 对，如何改造、改良这些老的体系，其实在我们的量化课程中也讲过不少，比如改造 RSI 成为智能 RSI，改造均线斜率为面积投影等等。

## 拉高视野 -- 看懂 2026 年 AI 交易的三大底层真相

宽粉：Aaron，刚刚我们聊过的，都是大模型能做交易。但是，大模型真的要完全取代传统的量化交易吗？这当中有没有什么坑？

Aaron: 对，近期在我们官网上，在 9 月中旬发布了 **《LLM 能做交易吗？三个实验讲透原理》**这篇文章。这篇文章揭示了三个过去大家可能没意识到的底层真相。

宽粉：来，我们一个一个拆。第一个真相是什么？

<!--也发布了两篇文章，一篇是介绍芝加哥大学布斯商学院的 Koijen 和 Levy 教授联合做市商巨头 Optiver 举办的 **Explaining Markets** 全球竞赛；

大模型在量化里真正的核心价值，是做「状态类比」与「置信度仓位风控器」
-->
Aaron：我们是基于 Quantpedia 上面的一篇文章，进行了延伸和拓展。我先介绍那篇文章的方法，它是让大模型给出以下输出指令：

如果当前是趋势上行，波动偏低，价格偏强，那就满仓干；如果是趋势下行，波动偏高，价格偏弱，那就以较低的仓位干。其它情况，就半仓。

那大模型决策的依据是什么呢？ 他们使用的是20 日涨跌幅、20 日年化波动率以及价格相对月均线的乖离率。

我们拿到那篇文章之后，第一个问题是：他为什么不用大模型来做股价的预测，而是用大模型去做仓位的控制？甚至在做仓位控制时，大模型输出的还不是一个精确的数字，而只是满仓、半仓、低仓这样离散化的档位。

于是我们就做了一些拓展实验。我们把最常见的几个动量特征，以历史数据的方式输入给大模型，同时，我们还把每一期数据，之后每一周的收益也提供给了大模型，希望大模型能从中学习到动量因子与远期收益之间的关系。

宽粉: 我猜大家会比较关心我们这次实验的结果。那我在这里跟大家分享一下。这个方案的年化收益低于买入并持有策略，但夏普比要高一些。具体的数据大家可以在我们匡醍的官网上查看。所以，在我们的实验中，尽管结果要好于 quantpedia 的那篇文章，但是毕竟绝对收益还低于买入并持有策略，更是远远落后于基于机器学习的模型。 Aaron, 你觉得问题在哪儿呢？

Aaron: 这就要聊到第一个真相了。那就是大模型是看不到数字的，是数字色盲。为什么呢？这是因为大模型拿到的所有输入，都是文本。对这些文本，大模型在预处理时会进行分词，而分词器是个数字色盲。这是第一个真相。

举个例子，在人类看来是小数的9.11，大模型会被它当成一串字符串，这一串数字在 token 化时，会被切成 9、.1 和 1 这样三个 token 的组合，这就构成了价格表征不连续。

更深入一点看，还不仅仅是分词的问题。在数学中，数字 7, 8，9三者之间，7和8，8和9之间的距离是相等的，而7和9之间的距离是7和8之间的两倍。但是，在大语言模型里，文本7，8，9是三个不同的 token，或者说三个高维向量，而这三个向量之间不一定能满足原来的数字之间的距离关系。距离是算术的核心，所以，大模型就很难算准算术题。

宽粉: 那这就是第二个真相了，距离失真。

Aaron: 第三个真相：Transformer 没有时序先验——方向可由因果掩码给出，但局部性、周期与状态转移只能从数据里学。

宽粉：所以，基于这三个底层原理，我们就不能够直接给大模型输入量价数据，并且要求它能预测出下一阶段的价格。但是可以像 PRISM 那样，把量价信息转换成为趋势突破、支撑等这样的离散或者说基于文本表达的信号，这样大模型就更擅长了。

那我们发表的另一篇，Explaining Markets 这场竞赛，又带给我们哪些技巧？

Aaron：这场竞赛是芝加哥大学的学者联合 Optiver，这是一家全球顶尖做市商，做的一场竞赛，目标也是看看大模型做交易会怎么样。刚刚结束的 Q3的比赛，主要是考大模型读财报的能力。

在这一期，官方披露了一个核心技巧，就是如何生成显性化的预期。

宽粉：对，这里代听众问一个问题。就是我们常常听到说，某公司财报发布后，因大幅不及预期，从而导致下跌。我就很好奇，那这个预期本来应该是多少，从哪里来？

Aaron: 主要有这样几个来源。一是分析师一致预期。比如在国内，有万得、东财 Choice 和<朝|ZHAO1>阳永续等机构会汇总并发布这个预期。第二个来源就是公司指引，比如上一季的电话会，公告给出的下季营收预期等；第三个来源是期权隐含预期。

宽粉: 那有这么多来源，如果它们彼此之间的预期不一致，我们应该采信哪一个？

Aaron: 所以，这就是 llm 可以一显身手的地方了，官方披露的核心技巧，就是让利用大模型强大的信息搜索、分析能力，在公司下一次财报发布之前，先生成一个预期指引，这样一旦公司的财报发布，llm 就可以判断业绩是不及预期，还是远超预期，从而对交易产生指引。

宽粉: 看来大模型在金融领域的用法还真多。

## 实战落地指南

宽粉：今天的内容非常丰富哈。我们介绍了欧奈尔的 CAN SLIM 投资方法，以及 PRISM-INSIGHT 这个框架，以及通过大模型强大的信息收集、综合能力，让它写一份市场预期指引。你刚刚还谈了更深入、更底层的一些东西，比如大模型不适合直接处理量价数据、进行股价预测的一些原理。

在节目的最后几分钟，咱们必须回应一下技术听众最关心的实操问题：如果我们的听众听完心痒痒，想自己把 PRISM-INSIGHT 部署起来玩，可行吗？该怎么下手？

Aaron：先说个人部署的费用问题。PRISM-INSIGHT 个人非商业使用完全免费，但是从开发者自己的实践看，如果你使用 OpenAI 系列的模型的话，大概一个月会花掉 300多美元的费用。

宽粉: 这是 API 价格还是订阅价格？

Aaron: 是 API 价格，如果你有 OpenAI 的订阅，那么价格会便宜不少。

宽粉：现在国模的能力也是不错了，如果改用国模，这个成本可能还会更低。另外一个更重要的问题，我从他的网站上看到，目前是支持美股和韩股。如果要在 A 股使用这个框架，那是不是要进行一些改造？

Aaron：对，这就是一个绝佳的极客改造工程了！首先我们要自己对接数据源，因为原版只接入了韩国股市和美股的数据。这里要注意的是，相当一部分数据是 Agent 在直接调用，所以，我们需要通过 MCP 或者 skills 等技术，对传统的数据源进行改造，才能让数据被 Agent 调用。

宽粉: 那有没有改造好的，直接以 Skill 或者 MCP 方式调用的数据源？

Aaron: 有的。比如东方财富提供了 skill 来让 Agent 调用行情和基本面数据，在我们的博客文章中也有介绍。当时这个 skill 在使用上还是免费的，现在情况怎么样，大家可能要自己去研究下。另外听众比较熟悉的通达信，最近他们也出了供量化使用的 SDK，其中也包括通过 Agent 调用方式。不过，通过这种方式调用，需要消耗 token，也就是说会产生一定的费用。

改造的第二步，就是要实现交易制度约束。比如我们交易制度中有 T+1 限制、涨跌停限制等，这些也要进行改造。

这些改造，现在都可以通过 AI 来自动完成，工作量不算大。可能最隐蔽的改造就是，如何实现参数对 A 股的适配。这点需要在运行过程中，慢慢去摸索。
