## /01 开场

宽粉：欢迎收听本期的《量化好声音》，我是宽粉。今天我们的选题是：大语言模型和 Agent 进入量化交易领域快两年了，到底走到了哪一步？

之所以会有这个疑问，是因为过去一年我们看到了太多两极分化的现象。一边是 GitHub 上只要跟“多智能体交易”沾边的开源项目，热度都极高，比如大家熟悉的 TradingAgents，Star 数已经突破了 10 万；但另一边，真正敢把系统拉到公开市场上去跑实盘或者实时模拟的，结果往往不太好看。

这也让很多听众朋友很纠结：既怕自己在这波 AI 浪潮里掉队，又实在摸不准大模型和 Agent 在量化交易里到底该怎么落地。今天，我们就把这件事聊透。

Aaron：没错。这段时间我们密集考察了六七个代表性项目。今天就跟大家盘一盘，业界到底是怎么用 LLM 和 Agent 做交易的，目前分化出了哪些流派，实战效果到底怎么样。

宽粉：说到实战检验，去年底海外有个叫 nof1.ai 的网站做过一场轰动全网的实验，把好几个 AI Agent 的实盘交易拿出来全网直播。但是九个月过去了，这个网站现在已经无人问津了。

原因很现实：参赛的 Agent 里，成绩最好的一个，夏普比<率|LI4>也只有 0.019，甚至还跑不赢普通散户。这也印证了一件事：在第一阶段的公开测试里，直接让通用大模型赤手空拳下场做交易，是完全不及格的。

但就在最近，我们注意到了韩国开发者开源的一个项目，叫 PRISM-INSIGHT。它可以直接在美股和韩国股市上跑实盘。更有意思的是，作者专门搭了个网站，把每天的交易结果公开直播，到现在已经连续跑了 390 天。看最近 6 个月的数据，韩国综合指数 KOSPI 跌了 10.36%，而它的模拟盘却拿到了 12.97% 的正收益；另外它还有一个小资金实盘，目前的收益率更是达到了 20.23%，大幅跑赢指数。

所以，我们今天的主角就是这个 PRISM-INSIGHT。

Aaron：对。今天我们会先拆解 PRISM-INSIGHT 的底层原理，再把它跟其他几个热门项目做个横向对比；节目最后，还会聊聊如果大家想自己动手部署、甚至改造成 A 股版本，具体该怎么下手。

宽粉：其实除了 PRISM-INSIGHT，现在 GitHub 上打着 Vibe Trading——也就是靠 Agent 做交易——旗号的项目还有不少。比如刚才提到的十万级网红项目 TradingAgents；还有专门针对 A 股的 AI 投研系统 easy-stock，有 1600 多个 Star；以及拿到 2800 多个 Star 的 Vibe-Research。

在这么多项目里，为什么我们今天单单挑中了 PRISM-INSIGHT 做主菜？它最打动你的亮点是什么？

Aaron：主要有四个原因。第一，就像你刚才说的，它有超过 390 天的公开实盘和模拟盘记录，而且业绩很稳健，这在开源项目里非常罕见。第二，它是一套真正跑通了“端到端”的实盘系统，而其他很多项目还停留在“辅助人做研究”的阶段，没法形成交易闭环。第三，它的投研逻辑并不是凭空捏造的，而是脱胎于华尔街传奇交易员威廉·欧奈尔的 CAN SLIM 成长股动量体系。这套体系本身经过了市场几十年的检验，非常经典。

更重要的是第四点：PRISM 并不是那种什么都甩给大模型的纯 Vibe Trading。它的边界划得很清楚——把需要综合研判的“模糊地带”交给大模型，把需要严格执行纪律的地方交给 Python 代码。

所以，不管你是想用 AI 辅助投资，还是想自己开发量化系统，去拆解它的架构、看看作者是怎么踩坑又是怎么改规则的，都能帮你省下大量的试错成本。

## 架构拆解

宽粉：好，有真金白银的战绩，有经典大师的理论打底，还有Agent和代码的明确分工。那我们就先从系统结构拆起，PRISM 到底是怎么运转的？

Aaron：PRISM 本质上是一个 Python 单体程序加上多个 Agent，共同组成了一条四段式的闭环流水线：筛选、分析、交易、反馈。

第一步是筛选阶段。这里完全不用大模型，而是用 Python 通过 yfinance 拉取行情数据，按预设的 6 条硬规则过滤股票。我们可以按交易时段和形态来理解这 6 条规则：

1. 看早盘放量：筛选早盘量增榜，要求成交量放大超过 30%。
2. 看早盘跳空：要求早盘向上跳空超过 1%，并且收阳线。
3. 看资金集中度：按市值和成交额集中度打分，取排名靠前的股票。
4. 看盘中动量：要求盘中涨幅在 3% 到 15% 之间，同样保持阳线。
5. 看尾盘强度：要求尾盘放量，涨幅在 0% 到 15% 之间，且收盘价要站稳在全天高位的阈值之上。
6. 看日线蓄势形态：也就是常说的放量横盘，要求量增率大于 50%，涨跌幅绝对值小于 5%，同时股价站上 20 日均线。

宽粉：听着特别亲切，这不就是淘股吧里各路打板高手天天念叨的看盘口诀嘛！早盘看跳空放量，尾盘看抢筹强度，日线看放量横盘。果然高端的策略，往往只需要最朴素的因子。

Aaron：哈哈，底层逻辑确实是相通的。在欧奈尔的 CAN SLIM 体系里，这一步其实对应的就是字母 S 和 L，也就是供需关系和领涨股的初步筛选。

等 Python 把候选池筛出来之后，就进入第二步：分析阶段。这时候大模型才正式登场。这一层安排了 6 个分析 Agent，分别负责：量价趋势、资金流向、公司财务状况、公司概览与同业对比、新闻催化，以及指数与宏观环境。

宽粉：诶，听到这儿我得打断一下。咱们匡醍官网之前发过一篇文章，叫《LLM 能做交易吗？三个实验讲透原理》。我印象特别深，你在文章里明确下过结论：大模型是没法直接从量价数据里提取交易信号的。那为什么 PRISM 这里又安排了一个 Agent 去做量价分析？这不矛盾吗？

Aaron：问到点子上了，其实并不矛盾。因为 PRISM 并不是把一堆原始 K 线数字直接扔给大模型去猜涨跌，它做的是**基于技术指标的趋势状态解读**。

具体来说，系统会先用代码工具算出 5 日、20 日、110 日、200 日均线，还有大家熟悉的 RSI、MACD 和布林带。Agent 的任务不是去算这些数，而是拿着算好的指标，去判断股价是不是突破了关键均线、当前处在什么支撑阻力位置。工具调用加上定性推理，就把大模型的算术短板给绕过去了。

宽粉：明白了，代码负责算指标，大模型负责看图说话、给趋势定性。那第二个“资金流向分析”呢？我记得这对应的是 CAN SLIM 里的字母 I，也就是机构投资者（Institutional Sponsorship）。

Aaron：没错。这个 Agent 专门盯三类资金的逐日买卖数据：机构、外资和散户。它要回答的核心问题是：现在到底是谁在买？资金流向和股价走势之间，是在共振还是在背离？

我们在之前的博客里也聊过，股市的走势其实是不同周期的资金博弈出来的。机构资金体量大、调仓慢，持股周期往往按季度算；而散户资金快进快出，按天甚至按小时算。如果你用频谱分析或者小波分析去拆解股价，就能清楚地看到不同频率的资金周期叠加在一起。

宽粉：我记得那篇文章！当时你用傅里叶变换去拆解上证指数，几乎精准还原了过去 20 年的大周期走势。把机构和散户的筹码博弈给量化出来了。

Aaron：是的。再往后的三个 Agent——公司财务状况、公司概览和新闻分析，就分别对应了 CAN SLIM 里的基本面与催化剂。其中，财务状况看的是当季和年度的业绩增长，对应字母 C 和 A；公司概览和新闻分析看的是新产品、新业务、新管理层以及近期的事件催化，对应字母 N。

宽粉：那最后一个“指数与宏观检索”，自然就是看大盘方向，对应最后一个字母 M（Market Direction）了。

Aaron：正是。

宽粉：好，分析层的 6 个 Agent 齐活了，把 CAN SLIM 的七个字母也对上了号。不过我有个技术上的疑问：我看 PRISM 的项目文档里说系统一共有 13 个 Agent，怎么咱们才数出来 6 个？剩下的藏哪儿了？

Aaron：13 个是项目早期的架构，后来作者做了一些精简。刚才说的 6 个都在第二步“分析阶段”。

到了第三步，系统设了一个“策略汇总 Agent”，专门把前面 6 份独立的分析报告揉成一份完整的投资策略。

再到第四步“交易环节”，还有两个核心 Agent：一个是“买入决策 Agent”，它会对照一套成文的评分表，给股票打出 1 到 10 分，同时写好建仓之后的加仓剧本；另一个是“卖出决策 Agent”，专门盯持仓股票的止盈和止损。

这 9 个模块走完，交易闭环就完成了。除此之外，系统还有两块盘后辅助模块：一个是沟通模块，负责把长篇大论的报告浓缩成 400 字的 Telegram 消息，翻译成多国语言推送给用户；另一个是日志与记忆模块，在每笔交易平仓后写复盘总结，提炼经验留给下一次交易参考。

宽粉：我帮你理一下啊：前面用 Python 跑 6 条规则做初筛；中间 6 个分析师 Agent 分头写报告，1 个汇总 Agent 合成策略，2 个交易 Agent 管买卖；盘后还有播报员和复盘员。

听完这套阵容，我产生了一个更底层的问题：为什么要搞得这么复杂？如果我写一个超级 Prompt，把所有工具和数据一次性塞给一个全能 Agent，让它直接给我出买卖结论，不行吗？一个投研系统到底拆几个 Agent 才合理？

Aaron：这其实是很多开发者上手做 Agent 系统时最容易踩的坑。在金融场景里，把任务拆给多个 Agent，最核心的价值就两个词：**「视角隔离」**和**「工具专有化」**。

我们可以做个思想实验。假如只用一个全能 Agent，你把一张刚刚突破新高的漂亮 K 线图、几篇热火朝天的题材小作文，还有一份负债率极高的财务报表，同时塞进它的上下文里，会发生什么？

大模型天生有一种“连贯性偏见”，它特别擅长编一个自圆其说的故事。当它看到股价在暴涨、新闻在吹捧的时候，它很容易在同一个上下文里自我洗脑，顺手就把高负债美化成“公司为了扩张做出的必要投入”，结果把致命的财务风险给忽略掉了。

宽粉：哈哈，这不就跟散户上头的时候一模一样嘛！看中了一只票，连它的亏损都能解读成“困境反转”。

Aaron：太形象了！所以为了防止大模型“上头”，你必须把它们物理隔离。

拆成 6 个独立 Agent 之后，每个 Agent 的系统提示词（System Prompt）和手里的工具都是锁死的。比如财务 Agent，它的任务就是冷酷地审视估值、盈利质量和资产负债表，它根本不知道外面市场炒得有多狂热，所以能保持审计员一样的冷静；新闻 Agent 手里只有搜索和网页抓取工具，专门去核实催化剂是不是真的；资金流 Agent 只看韩国投资证券（KIS）的席位数据。

每个分析师先在自己的盲区里给出独立判断，最后再交给汇总 Agent 和买入决策 Agent 去碰撞、权衡。而且这样拆开还有一个工程上的好处——省钱。基础的信息整理可以用中等模型，盘后写摘要用轻量级模型，只有最后拍板买卖的那一哆嗦，才调用最贵、推理最强的模型。既保证了客观性，又把成本控住了。

宽粉：懂了！单 Agent 容易“屁股决定脑袋”，自己说服自己；多 Agent 就是人为制造信息隔离，让财务的归财务，情绪的归情绪，最后再坐下来开投委会。

那如果咱们把视野再拉宽一点，把 PRISM 和前面提到的 TradingAgents、easy-stock、Vibe-Research 放在一起看，它们在多 Agent 的设计思路上有什么本质区别？

Aaron：这四个项目正好代表了目前 AI 赋能投研的四种典型流派。

先说名气最大的 **TradingAgents**，它的核心机制是**「多空辩论」**。它前面也有基本面、情绪、新闻、技术四个分析师，但最精彩的设计在后面——它设了一对立场完全对立的研究员：一个死多头，一个死空头。这两个 Agent 会拿着前面四个分析师的材料，进行多轮结构化辩论。因为金融市场里永远同时存在看涨和看跌的证据，让多空双方吵一架，就能把单边思维藏着的风险点逼出来，最后再由风控和交易员拍板。不过，TradingAgents 的定位偏学术和实验，没有对接实盘接口，也没有长期跑出来的公开账本。

宽粉：TradingAgents 是搞“辩论赛”。那另外两个项目呢？

Aaron：另外两个项目 **easy-stock** 和 **Vibe-Research** 就非常务实了。它们不做全自动无人交易，而是做**「本地投研工作台」**——决策权留在人手里，让 Agent 当超级助理，帮你干脏活累活。

但这两个助理的特长完全不同。**easy-stock** 专为 A 股短线和打板选手打造。它不让大模型直接看原始 K 线，而是先用 Go 语言在后端把连板梯队、晋级率、题材强度、情绪周期这些指标算成结构化数据，再让 Agent 去解读。它还有个很接地气的功能：每天定时去抓取雪球、淘股吧上几个知名大 V 的复盘贴，让 AI 提炼出今天市场最大的共识是什么、分歧在哪儿、明天开盘要验证什么信号。甚至还能从逻辑、结构、风险、策略匹配度四个维度，给你的持仓打分。

宽粉：怪不得在国内挺火，这简直是给短线打板选手量身定做的外挂啊。那 Vibe-Research 呢？

Aaron：**Vibe-Research** 走的是深度基本面路线，一口气接了 A 股、港股、美股的 168 个数据接口。它在工程上最值得所有开发者学习的一点，叫**「数字出处审计」**。大模型写研报最怕什么？最怕它张口就来、自己编财务数字。所以在 Vibe-Research 里，程序会强制核对 AI 输出的每一个数字——这个数要么能在接口数据、研报原文里找到一模一样的出处，要么必须列出明确的计算公式。这就从根上治好了最让人头疼的“数据幻觉”。

而我们今天聊的 **PRISM-INSIGHT**，和前面三个最大的不同，就在于它不满足于只当参谋，而是往前迈了一大步，把“感知、分析、实盘下单、盘后复盘进化”的完整闭环全跑通了。

宽粉：说到这儿，我给你总结一下这四个流派：TradingAgents 是“辩论派”，靠多空吵架暴露风险；easy-stock 是“游资助理派”，专攻 A 股情绪和连板梯队；Vibe-Research 是“严谨审计派”，死磕基本面与数字出处；而 PRISM 则是“实战闭环派”，直接下场真刀真枪做交易。

这一下子就让我对 PRISM 的最后一个环节——“盘后复盘反馈”产生了极大的好奇。我看 PRISM 文档里提到了两个很有意思的机制：一个是生成摘要时的“评估-优化循环”，另一个是平仓后写交易日志、提炼交易“直觉（Intuitions）”，再反哺给下一次买入决策。

这其实戳中了大家特别关心的一个痛点：我们手头都有一些一手的交易记录和优质数据，很想喂给 Agent 让它越做越聪明，但普通人又不可能去重新训练或微调大模型。那在不改模型权重的前提下，光靠记交易日记、攒正反面案例，真能让系统的交易水平持续进化吗？

Aaron：你问到了目前 AI 工程界最核心的一个前沿方向。不改模型权重，光靠积累历史交易的正反例闭环来提升决策能力，在原理上不仅完全可行，而且现在学术界给它起了个专门的名字，叫**「上下文强化学习」**，或者叫**「自然语言空间的强化学习」**。

宽粉：听起来很酷，但不改神经网络的参数，怎么实现强化学习的效果呢？

Aaron：我们对比一下就明白了。传统的强化学习，是在每一局游戏或每一笔交易结束后，根据赚了还是亏了，通过反向传播去修改神经网络的权重，让模型下次遇到类似情况时做出更好的动作。

在大模型应用里，我们确实改不动那几千亿个参数，但别忘了，大模型有强大的**上下文学习能力（In-Context Learning）**。如果我们把每一笔交易当时为什么买、市场是什么状态、最后赚了还是亏了、事后复盘原因是什么，全部结构化地存下来，提炼成一个持续更新的“经验规则库”。等下次遇到形态相似的股票时，系统自动把最相关的历史经验检索出来，塞进买入决策的提示词里。

从数学上看，虽然底层的模型权重没变，但因为输入的条件变了，模型输出决策的**条件概率分布**已经实实在在地改变了！换句话说，我们不是在“参数空间”里做梯度下降，而是在“提示词空间”里做策略迭代。

宽粉：相当于给大模型配了一本随时翻阅的“错题本”！每次下单前先翻翻错题本，看看以前在同一个坑里是怎么摔倒的。

Aaron：对！而且不止是错题本。我昨天专门去翻了 PRISM 仓库最近一周的代码提交记录，发现作者刚刚做了一次非常惊艳的升级——把原来的“单向写检讨”，升级成了**「正反例对照提取法」**。

以前它的记忆系统很简单，哪笔交易亏了，就让 AI 写篇检讨书。但作者发现这样不够，因为市场里有很多“双胞胎陷阱”。于是他改了逻辑：系统会把历史上真正走出主升浪的大牛股（正样本），和那些买入时各项指标、突破形态看起来一模一样，最后却止损出局的“假突破股票”（也就是机器学习里的困难负样本 Hard Negatives）摆在一起。然后让大模型做对比阅读，专门去找这两拨长相酷似、结局却天差地别的股票，在基本面、催化剂或者量价细节上到底有什么微妙的差异，把这种差异提炼成分辨真假突破的“直觉”。

宽粉：哇，这个思路太赞了！就像老中医看病或者老股民复盘一样，光看成功的案例没用，得把“真突破”和“假突破”的 K 线和基本面并排摆在桌面上找不同，这样练出来的盘感才最毒辣。那系统怎么知道它提炼出来的这个“直觉”是真有用，还是瞎总结呢？

Aaron：作者在这里做了一个非常严谨的闭环检验。他在代码里专门写了一个统计函数，持续对比两组交易：一组是“参考了历史直觉并调整了打分”的交易，另一组是“没参考历史直觉”的交易，看前者的实际胜率和平均收益到底有没有跑赢后者。如果某条提炼出来的直觉，在后续实战里胜率低于 30%，或者超过 90 天都没派上用场，清理脚本就会自动把它淘汰掉。

所以你看，“正反例对比找不同 + 实战胜率检验 + 劣质经验自动淘汰”，这三步合在一起，已经是一套相当完整的非参数化强化学习系统了。

## 审视欧奈尔体系——60 年代的方法今天还管用吗？

宽粉：聊完技术架构，咱们进入第二个核心议题，也是我个人最好奇的部分：PRISM 背后的交易哲学——**威廉·欧奈尔的 CAN SLIM 体系**。

刚才我们已经看到了 PRISM 是怎么用代码和 Agent 把这套体系装进去的。但在深入细节之前，我得先替听众抛出一个最大的质疑。

欧奈尔是在 1960 年代总结出这套方法的，距今已经六十多年了。一套人尽皆知的屠龙技，放到今天的市场上，真的还灵吗？

我举个最现实的矛盾：在 CAN SLIM 体系里，同时用到了基本面和量价两类信息，但这两者的更新频率差太多了。在 60 年代，信息传播靠报纸和邮寄财报，市场消化一条财报消息可能要花好几个星期。但今天呢？互联网、高频算力加上 AI，任何一条基本面消息一出来，往往一两个交易日就彻底反映在股价里了。而在剩下的几十个交易日里，基本面根本没有新消息，只有量价数据每秒钟都在跳动。

在这种秒级定价的时代，基本面和量价的周期严重错配，CAN SLIM 里的基本面分析到底还有多大价值？每天跳动的量价数据，难道还不足以反映一切吗？

Aaron：你这个问题非常尖锐，其实问到了所有交易者都绕不开的“市场有效性”之问。如果信息一两天就定价完了，60 年代的欧奈尔体系是不是早就该进博物馆了？

我的答案很明确：**信息传播的速度确实变成了秒级，但大资金建仓的物理过程，依然是以“周”和“月”为单位的。基本面在今天的作用，早就不是用来做“日内抢跑”了，而是用来给量价异动做“去伪存真”，以及给持仓周期做“定性”。**

我们可以从两个层面来拆解你说的周期错配：

第一，**为什么一两个交易日消化不完基本面？** 这就回到刚才说的资金结构了。像公募、养老金、长线外资这些大型机构，受限于风控合规和市场流动性，哪怕今晚一家公司财报大超预期，它们也不可能在第二天集合竞价把几百亿的仓位一口气买满——那样会把股价直接买崩。所以，第一、二个交易日的跳空大涨，往往是游资、量化事件驱动资金和最敏锐的买方打出来的“点火信号”。而在随后的两三个月里，随着产业逻辑不断被验证、上下游订单陆续落地，大机构在回调中分批建仓，才真正推起了后面完整的主升浪。

宽粉：也就是说，消息虽然一秒钟就能传遍全网，但大机构的真金白银得花好几个月才能搬进场。这就留下了时间窗口。那第二个层面呢？为什么量价不能替代基本面？

Aaron：因为**单纯看量价，太容易遇到刚才说的“同形异质”——也就是长相一模一样的假突破。**

你想想，在某一天早盘，一只纯靠小作文炒作、主业连年亏损的概念股，和一只刚刚拿下海外大单、行业迎来产能紧缺的硬核成长股，它们在分时图和日 K 线上表现出来的“放量突破、资金净流入”，可以是完全一模一样的。如果系统只看量价，根本分不清这是“主升浪的起点”，还是“游资拉高出货的诱多”。

在没有财报发布的平时那几十个交易日里，基本面扮演的其实是一个**「慢变量过滤器」**和**「持仓信心锚」**。只有确认了基本面的底色是真的，当股价在突破后第五天遇到大盘回调、缩量跌了 4% 的时候，系统才敢判断这是正常洗盘、继续拿住，而不是吓得赶紧割肉。

宽粉：这句话总结得太到位了：**量价是快变量，负责提供开火的扳机；基本面是慢变量，负责过滤假信号，决定这只票你到底敢拿多久。**

好，既然证明了 CAN SLIM 并没有过时，那我们顺着往下挖：这套经典打法，以前的传统量化肯定也写过无数遍了，为什么今天值得用大模型和 Agent 重做一遍？如果回到欧奈尔的原著《笑傲股市》，在 CAN SLIM 这七个字母里，到底哪些是传统量化早就写烂了的，又有哪些是过去根本写不出来、必须靠今天的大模型才能真正实现的？

Aaron：这个问题切中了 AI 投研最核心的增量价值！常言道，华尔街没有新鲜事，投资逻辑如山岳般古老，但技术工具的革新，让我们有机会把过去做不到位的老体系真正补齐。

我们挨个字母来看。前两个字母 **C（当季业绩增速）** 和 **A（年度盈利持续增长）**，在过去几十年里是最容易被传统量化写进代码的。任何人写几行 SQL 查一下财务数据库就能筛出来。今天大模型在 C 和 A 上的增量相对有限，主要是去读财报附注，帮我们剔除掉那些靠卖房、卖子公司或者汇兑损益凑出来的“假增长”，再比对一下业绩有没有超市场预期。

但是到了第三个字母 **N**，情况就完全不一样了。在欧奈尔的原著里，N 包含了两层含义：**一是新产品、新服务、新管理层或行业新变局；二是股价从良好的整理形态中走出，创出新高（New Highs）。**

请注意，欧奈尔把“基本面之新”和“价格之新”浓缩在了同一个字母 N 里。他研究了几十年的大牛股后发现，95% 的超级牛股在启动时，背后都有重大的基本面“新变化”做引擎，同时伴随股价突破平台创新高。这一点做 A 股的朋友肯定也深有体会——股票还是那些股票，但每年的大牛股背后都有全新的产业故事或题材催化。

那我现在反问你一句：在过去几十年的传统量化里，宽客们写代码的时候，是怎么写 N 这个因子的？

宽粉：代码又读不懂公司是不是发了颠覆性新产品，那肯定只能偷懒，直接写一行“收盘价创 52 周新高”呗！

Aaron：完全正确！过去几乎所有复刻 CAN SLIM 的量化策略，都把 N 简化成了单一的价格指标——股价接近或创出 52 周新高。结果就是买椟还珠，把 N 最核心的灵魂——“因为基本面出现了新产品、新技术或行业新变局，从而推动股价创新高”——给硬生生阉割掉了！

而今天，**这恰恰是大语言模型发挥价值的第一个核心突破口**。在 PRISM 里，一旦量价脚本发现某只股票放量异动，它的新闻分析 Agent 和公司概览 Agent 就会立刻调用搜索和爬虫工具，去读最新的公司公告、新闻稿和行业报道，用自然语言理解能力去核实：这次拉升背后，到底有没有实质性的新产品发布、大额订单落地或者产业政策催化？如果查了一圈发现什么都没有，只是股价莫名其妙干拔，买入决策 Agent 就会直接把分数压下来。

宽粉：太通透了！以前写因子是“只看新高，不问缘由”，现在有了大模型，终于能做到“既看价格新高，又查背后新意”了。那剩下的 S、L、I、M 四个字母呢？

Aaron：第四个字母 **S（供求关系）**，看的是流通盘大小、有没有回购、突破日是不是放量 50% 以上，这些用传统代码很容易算清楚。最后两个字母 **I（机构认同度）** 和 **M（大盘方向）**，也基本是传统量化的强项。

唯独第五个字母 **L（Leader or Laggard，买领涨龙头，不买落后跟风股）**，让传统量化撞上了第二道天花板。

欧奈尔非常强调，买股票一定要买行业里的真龙头，绝不能贪便宜去买跟风补涨的杂毛股。为了量化这件事，欧奈尔当年发明了著名的 RS 指标（相对价格强度，从 1 到 99 打分），看这只股票过去一年的涨幅跑赢了全市场百分之多少的股票。

宽粉：这不就是咱们 A 股游资常说的“龙头战法”嘛，只买涨得最凶的那个。

Aaron：对，但问题来了：**“短期价格涨得快”，就一定等于“产业真龙头”吗？** 未必！在题材炒作初期，一只边缘蹭概念的小票可能连拉几个涨停，RS 分数瞬间冲到 99，但它在产业链里毫无壁垒和议价权，潮水一退立马原形毕露。

过去的计算机读不懂产业链结构，只能用价格动量来近似代替龙头地位。而现在，**这就是大模型带来的第二个核心突破口**。像 PRISM 里的行业分析 Agent，或者前面提到的 Vibe-Research、easy-stock 里的产业地图模块，大模型可以通过读研报和主营构成，直接帮你理清楚：在 HBM 内存或者光模块产业链里，到底谁掌握核心产能、谁的毛利率最高、谁真正在给海外大厂供货。

只有把**「定性的产业龙头地位」**和**「定量的价格相对强度」**结合起来，欧奈尔的字母 L 才算真正完整落地了。

宽粉：听完这一段，真有种任督二脉被打通的感觉！大家完全可以顺着这个思路举一反三：过去几十年，不管是欧奈尔的 CAN SLIM、彼得·林奇的成长股分类，还是巴菲特的护城河理论，以前我们做量化的时候，只能把里面能写成财务指标和量价公式的部分摘出来，而那些真正决定成败的定性维度——比如 N 里的新业务变局、L 里的产业链壁垒——全都因为代码写不出来而被迫丢掉了。今天大模型的出现，本质上是让我们第一次有工具，把当年被传统量化遗弃的“定性拼图”重新捡回来，装进自动化系统里。

Aaron：总结得非常精准。不过更有意思的还在后面：当 PRISM 的作者真正用 AI 补齐了 N 和 L，把这套系统放进韩国和美国市场实盘跑了一年多之后，他迎头撞上了另一个残酷的现实——即便选股端进化了，如果你照搬欧奈尔 60 年代定下的某些机械持有规则，在今天的市场里照样会亏大钱。

宽粉：哦？我记得作者在更新日志里吐槽过，说系统经常“卖飞大牛股”？

Aaron：对，这正好呼应了你前面说的“时代变了，市场微观结构变了”。作者做过一次统计：在系统买进后 60 个交易日内涨幅超过 30% 的韩国牛股里，这些股票最高涨幅的中位数达到了 60%，但系统实际平仓拿到手的利润中位数，居然只有可怜的 **2%**！绝大多数大牛股，刚涨了一点就被移动止损或者卖出 Agent 给提前洗出去了。

为了解决“拿不住牛股”的毛病，作者决定去引入欧奈尔体系里最著名的**「8 周持有规则」**。欧奈尔原著是这么规定的：如果一只股票从突破点算起，在 1 到 3 周内快速上涨满 20%，就具备成为超级牛股的潜质，应该至少拿满 8 周，或者一直拿到跌破 50 日均线为止。

但作者很聪明，他没有拍脑袋直接上线，而是拿系统过去一年多真实跑出来的交易台账做了一次历史回放测试。结果算出来大吃一惊：**如果原封不动地照搬欧奈尔“涨满 20% 就死拿到 50 日均线”的规则，韩股的累计收益反而倒退了 43 个百分点，美股也倒退了整整 40 个百分点！**

宽粉：倒退 40 多个百分点？！为什么欧奈尔当年的黄金法则，放到今天的市场上会失效得这么惨？

Aaron：因为今天市场的短线波动结构跟 60 年代完全不同了。作者把数据拆开一看，瞬间找到了病根：**在今天的市场里，凡是在买入后 1 到 3 个交易日内就急涨 20% 的股票，绝大多数根本不是什么机构长线趋势股，而是受短期消息刺激的情绪脉冲！**

你想想，一只股票两三天暴涨 20%，这时候股价离下方的 50 日均线非常遥远。如果你机械地执行“不破 50 日均线不卖”，接下来几天游资一撤退，股价快速A字杀下来，等你终于碰到 50 日均线的时候，那 20% 的浮盈早就回吐干净，甚至直接变成亏损出局了。

相反，回放数据清楚地表明：今天真正能走出长牛的领涨股，往往是在买入后 **4 到 15 个交易日**内，经过充分换手消化、稳步推升达到 20% 涨幅，而且当时股价并没有过度偏离 50 日均线的股票。

宽粉：太真实了！三天暴涨 20% 的往往是游资点火的一日游，死拿必坐过山车；反而是花一两周稳步推上去的，才是机构真金白银建仓的主升浪。那作者最后是怎么改这条规则的？

Aaron：他在今年 10 月初上线的新版本里，对欧奈尔的经验法则做了三刀大手术：

第一刀，**改良领涨股持有规则**。1 到 3 天急涨 20% 的股票，坚决不给免死金牌，依然按常规的移动止损及时落袋为安；只有花 4 到 15 个交易日稳步涨满 20%、且没有严重偏离 50 日均线的股票，才触发“领涨股持有模式”——在最长 40 个交易日内，只要收盘不破 50 日线、也不破首次买入成本价，就稳稳拿住。

第二刀，**用 AI 情景加仓替代机械阶梯加仓**。放弃过去那种每涨 2% 就机械加仓的老办法，改成首仓按波动率买 30% 到 80%，同时让买入 Agent 提前写好 2 到 4 个加仓触发剧本——比如突破某个阻力位，或者回调到某条均线企稳——后续由代码监控，满足条件才执行金字塔加仓。

第三刀，**果断砍掉被证伪的规则**。比如欧奈尔门徒后来推崇的“口袋支点（Pocket Pivot）”放量指标，还有按 ATR 波动率设止损的方法，在 PRISM 的实盘台账回放里都被证明没有正收益甚至起了反作用，作者二话不说，全部写进废止台账里砍掉了。

宽粉：你看，这个演进过程特别有启发：要把经典大师的体系交给 AI 落地，绝不能搞教条主义。**选股端，用大模型补齐当年算不出来的定性拼图 N 和 L；交易端，用真实的实盘台账去修正 60 年代的老参数。**

Aaron：没错。其实怎么用现代方法去改造经典指标，在我们的量化课程里也讲过很多案例，比如把传统 RSI 改造成智能自适应 RSI，把均线斜率改造成面积投影等等，底层思路都是一脉相承的。

## 拉高视野 —— 看懂 2026 年 AI 交易的三大底层真相

宽粉：聊到这儿，我们已经看到了大模型在投研和交易里的巨大潜力。但咱们也得泼一盆冷水：大模型真的能包打天下、彻底取代传统量化模型吗？这里面有哪些容易踩的坑？

Aaron：这就要回到你前面提过的那篇文章了——我们官网在 9 月中旬发表的**《LLM 能做交易吗？三个实验讲透原理》**。我们在做那组实验的时候，挖出了三个很多人以前没意识到的底层真相。

宽粉：来，咱们一个一个拆。你们当时是怎么做实验的？

Aaron：我们的实验其实是受了 Quantpedia 上一篇论文的启发。那篇论文的做法很有意思：它把 20 日涨跌幅、20 日年化波动率，还有股价相对月均线的乖离率喂给大模型，然后让大模型给出仓位指令——如果判断当前是趋势上行、波动偏低、价格偏强，就满仓；如果趋势下行、波动偏高、价格偏弱，就低仓位；其他情况就半仓。

我们读完那篇论文后，脑子里冒出的第一个问号就是：为什么作者不用大模型直接预测涨跌幅度，而是只让它做仓位控制？甚至连仓位控制都不敢让它输出具体的百分比数字，只让它在“满仓、半仓、低仓”这三个离散档位里做选择？

为了搞清楚背后的原因，我们自己动手做了一组拓展实验：把常见的动量特征历史数据喂给大模型，同时把每一期数据对应的未来一周真实收益也告诉它，想看看大模型能不能自己从数据里学出“动量因子与未来收益”之间的定量关系。

宽粉：实验结果怎么样？大模型学会了吗？

Aaron：结果非常耐人寻味。我们改进后的方案，虽然跑赢了 Quantpedia 原文的方法，夏普比<率|LI4>也比简单买入并持有要高一些，但它的绝对年化收益依然没跑赢买入并持有，跟传统的机器学习量化模型比起来，更是差了一大截。具体的数据图表，大家感兴趣可以去我们匡醍官网上看。

宽粉：这就奇怪了，大模型连奥数题都能做、代码都能写，为什么喂给它历史因子和收益率，它却学不会预测股价呢？病根到底在哪儿？

Aaron：这就揭开了**第一个底层真相：大模型其实是“数字色盲”。**

为什么这么说？因为大模型接收的所有输入都是文本。在预处理阶段，分词器（Tokenizer）会把数字当成普通字符串来切分。举个最直观的例子：人类看到 `9.11`，一眼就知道它是一个比 9 稍微大一点的小数；但在大模型的分词器眼里，它可能会被切成 `9`、`.` 和 `11` 三个独立的 Token。这就导致连续变化的价格，在模型内部变成了断裂的符号碎片。

宽粉：连数字都是被切碎了看的，那它对数字大小的感觉岂不是乱套了？

Aaron：没错，这就引出了**第二个底层真相：向量空间里的“距离失真”。**

在数学上，数字 7、8、9 排在一条直线上，7 到 8 的距离和 8 到 9 的距离严格相等，7 到 9 的距离刚好是它们的两倍。但在大语言模型里，文本 `7`、`8`、`9` 对应的是三个高维词向量。这三个高维向量在语义空间里的夹角和距离，根本不严格满足数学上的等距关系！而算术和回归预测的核心就是“距离度量”，底层距离都变形了，大模型自然算不准定量的价格规律。

宽粉：第一个真相是分词导致的“数字色盲”，第二个真相是向量表征导致的“距离失真”。那第三个真相呢？

Aaron：**第三个底层真相是：Transformer 架构天生缺少“时序先验”。**

什么意思呢？大语言模型虽然知道哪个词在前、哪个词在后，但它理解的是“文字排队的先后顺序”，而不是物理世界里“时间流逝的节奏”。在金融时间序列里，局部的连续波动、均值回归的周期、市场状态的平滑转移，这些强时序规律，Transformer 架构本身是完全没有概念的，只能硬着头皮从海量数据里去死记硬背。

宽粉：听完这三个底层真相，一切就都说得通了！因为大模型有**数字色盲、距离失真、缺少时序感**这三大先天基因缺陷，所以我们绝不能把原始的 K 线数字和量价表格直接塞给它去算涨跌。

反过来，像 PRISM 或者 Quantpedia 那样，先用 Python 代码把数字算好，转化成“突破均线”、“缩量回调”、“波动偏高”这种定性的文字标签，再让大模型去做状态归类和仓位档位选择——这就完美避开了它的算术短板，发挥了它的语义推理长板！

除了这三大原理，我看咱们官网最近还发了另一篇文章，介绍了芝加哥大学联合全球顶级做市商 Optiver 举办的 **Explaining Markets** 全球竞赛。这场顶尖比赛又给我们透露了什么实战秘籍？

Aaron：这场比赛专门测试大模型在真实金融市场里的实战能力。刚刚结束的第三季度赛程，核心考题就是让大模型读财报、做交易决策。

在赛后总结里，官方披露了一个非常含金量的实战技巧，叫**「生成显性化的事前预期」**。

宽粉：说到“预期”，我替听众问个常见的问题。我们看盘的时候经常听到一句话：“某某公司虽然业绩大涨，但因为不及市场预期，股价开盘跌停。”很多人就纳闷了：这个所谓的“市场预期”到底是个什么数？从哪儿冒出来的？

Aaron：在专业机构眼里，预期主要来自三个地方：第一是卖方分析师的一致预期，比如国内的万得、东财 Choice、<朝|ZHAO1>阳永续都会汇总发布；第二是公司管理层自己的业绩指引，比如上一季财报电话会或业绩预告里给的区间；第三则是期权市场隐含的波动与方向预期。

宽粉：那问题来了，如果这三个地方给出的预期不一样，甚至互相打架，交易的时候该听谁的？

Aaron：这恰恰就是大模型大显身手的地方！Optiver 竞赛官方披露的核心打法就是：在公司财报发布**之前**，先派大模型去全网搜集分析师研报、公司历史电话会指引和行业上下游动态，把多方信息综合起来，提前写好一份明确的“事前预期基准”。

等财报真正发布的那一刻，大模型不再是孤立地看财报数字好不好看，而是拿着刚出炉的财报，去跟自己提前写好的那份“预期基准”做逐项比对。到底是超预期还是不及预期、具体是哪个业务分部超了预期，一比就清清楚楚，交易信号自然也就出来了。

宽粉：妙啊！不让大模型事后诸葛亮，而是让它在财报发布前先立个靶子，财报一出立刻对比开火。看来只要找对位置，大模型在金融交易里的巧劲儿还真不少。

## 实战落地指南

宽粉：不知不觉今天聊了好多干货。我们从欧奈尔的 CAN SLIM 体系，拆解到了 PRISM-INSIGHT 的多 Agent 闭环架构，又聊到了大模型的三大底层局限，以及用大模型生成财报事前预期的实战技巧。

在节目的最后几分钟，咱们必须回应一下技术听众最关心的实操问题：如果大家听完心痒痒，想自己把 PRISM-INSIGHT 部署起来跑一跑，门槛高不高？大概要花多少钱？

Aaron：先说大家最关心的费用。PRISM-INSIGHT 这个开源项目本身，个人非商业使用是完全免费的。主要的开销在大模型调用费上。根据原作者自己的实盘账单，如果全套使用 OpenAI 系列的模型，一个月跑下来大概需要 300 多美元的 API 费用。

宽粉：一个月 300 多美金，折合人民币两千多块，这是纯调 API 的账单对吧？

Aaron：对，是按量付费的 API 账单。如果你能结合订阅账号或者做一些缓存优化，成本会降下来不少。

宽粉：而且现在咱们国产大模型的能力也很能打了，如果把里面的分析环节换成性价比更高的国产模型，这个成本估计还能砍掉一大截。

那另一个更关键的问题来了：PRISM 原版目前只支持美股和韩股。如果我们的听众想把它改造成 **A 股实盘版本**，需要动哪些手术？

Aaron：这就真的是一个非常棒的极客改造工程了！想要移植到 A 股，核心要过三道关。

第一关是**数据源改造**。原版接的是美股和韩股接口，换成 A 股，我们得把行情、财务和资金流数据全换成本土数据源。这里有个技术细节要注意：PRISM 里有相当一部分数据是让 Agent 在推理过程中自己去调用的，所以我们不能只写普通的 Python 脚本，而是需要把本土数据源封装成 **MCP** 或者 **Skills** 的形式，让大模型能直接伸手调用。

宽粉：那现在国内有没有现成做好了、能直接让 Agent 通过 Skill 或 MCP 调用的金融数据源？

Aaron：还真有！比如东方财富前段时间就推出了官方的 Skill，专门让 Agent 直接拉取 A 股行情和基本面数据，我们在之前的博客里也专门测评过。当时用起来还是免费的，现在的收费策略大家去试的时候可以再确认一下。另外，量化圈非常熟悉的通达信，最近也推出了面向量化和 Agent 的 SDK，同样支持大模型直接调用，不过那种方式会消耗平台的 Token 额度，需要一定的费用。

宽粉：数据源这关解决了，后面两关呢？

Aaron：第二关是**交易制度适配**。韩国和美国股市都是 T+0 且没有 10% 的涨跌停限制（韩股是 30%），而 A 股有严格的 **T+1 制度**，还有 10%、20% 的涨跌停板限制。所以原版里涉及日内止损、仓位计算的规则，必须按 A 股制度重写一遍。

好消息是，第一关的数据源对接和第二关的交易规则修改，现在靠 AI 编程助手就能帮我们干掉八九成的代码活，工程量并不算大。

真正最考验内功的是第三关——**策略参数的本土化校准**。就像前面我们看到 PRISM 作者用回放台账把欧奈尔的“8 周规则”改成了“4 到 15 天规则”一样，A 股的游资生态、板块轮动速度和美股、韩股又有很大差异。到底突破放量多少算有效、拿多少天止盈最划算，这就需要大家把系统跑起来之后，用 A 股的真实回放数据去慢慢打磨了。

宽粉：说白了，代码移植 AI 能代劳，但参数调优和市场脾气的摸索，还得靠咱们量化人自己的内功。
