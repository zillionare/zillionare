## 今日拾遗

### Python 3.15刚刚发布！

![](https://blog.python.org/_astro/python-3.15.Cl03WkPb_2ux1jo.webp)

Python 3.15.0 刚刚发布。

重点更新：默认编码改为 UTF-8，引入显式 lazy import 加快启动，新增 `sentinel`、`frozendict` 内置类型，推导式支持解包。

此外，实验性 JIT 性能提升约 8%；标准库新增专用性能分析包与采样分析器 Tachyon；Windows 64 位改用尾调用解释器，macOS 默认启用自由线程。

为配合此次发布，Barry Warsaw 还开发了一个 TUI 的小游戏，带你熟悉 Python 3.15的各项新功能。食用方法是：

`uvx --python 3.15 whatsnewt`

这是一个复活节彩蛋。<sup>[1](https://blog.python.org/2026/10/python-3150-final-is-here/)</sup>

### 研究员警告加密算法可能在数月内失效，呼吁进入地堡模式

OpenAI一次性公开377项数学成果，令加密行业风声鹤唳。

以太坊研究员Justin Drake 认为，椭圆曲线具有丰富的代数结构，可能存在 Schoof、Frobenius、双线性配对等经典技巧，AI或能从公钥反推私钥，广泛使用的ECDSA签名算法可能在数月内而非数年后失效，呼吁进入"地堡模式"，把资金迁至从未签署过交易的新地址。

Vitalik Buterin亦建议正视AI对密码学的冲击，优先采用基于哈希而非格密码的方案，参数设置更保守。

防御手段包括地址迁移、强化冷钱包，以及借助"risq list"追踪公钥已暴露的地址。<sup>[2](https://www.cls.cn/detail/2500328)</sup>

AI评论：如果签名体系真的被高效攻破，暴露地址上的币价值会大幅下跌，甚至在一段时间内出现链上抽取潮；但只要账本本身仍被承认，且协议能完成向抗量子或抗 AI 签名的升级，整体价值未必归零

### 公募基金运作管理办法修订征求意见支持权益发展

中国证监会依据证券投资基金法等法律法规落实推动公募基金高质量发展行动方案形成三份配套文件。现行规则为证监会令第104号，自2014年发布至今已逾10年，明确产品注册、申购赎回、投资限制、收益分配与持有人大会等事项。本次完善压实管理人职责，优化监管指标与机制以提高灵活度，为创新预留空间助力引入中长期资金。 <sup>[3](http://www.csrc.gov.cn/csrc/c100028/c7663393/content.shtml)</sup>


## 大厂动态

### Optiver 公布 Explaining Markets 首轮竞赛赢家

长期以来，市场收益的可解释性始终停留在较低水平，并且难以扩展到样本外。Optiver 联合 Explain Markets 发起了挑战，通过 AI 大模型来探索收益的可解释性。

第一轮竞赛刚刚结束，大约200个 agent 参加了比赛。多年来，这项任务的最先进水平（SOTA）样本内决定系数（R²）只有5%到10%，而仅仅一个季度，参赛者借助多种模型与技术，将其提升到了超过25%（且为样本外结果）。

下一轮比赛将在10月12日起开始，并且主办方提供了新的数据。<sup>[4](https://x.com/rkoijen/status/2108540381159628809)</sup>

### WorldQuant第六届全球量化锦标赛结束，尼中台选手分获前三

WorldQuant本届赛事注册规模约15.6万人，较2024年约3.8万人大幅增长。

总决赛于10月6日至7日在新加坡举行，13支决赛队伍现场开发并展示新Alpha，争夺10万美元奖金池，评审聚焦原创性、质量与分散度。

比赛依托BRAIN仿真平台开展，超4万名女性参赛，约28%参与者来自非洲，单人参赛显著增加，凸显AI工作流正扩大量化研究参与面。 <sup>[6](https://www.worldquant.com/ideas/worldquant-announces-winners-of-the-2026-international-quant-championship/)</sup>
