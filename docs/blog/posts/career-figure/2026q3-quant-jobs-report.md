1. **入场三件套 = Python + 统计/概率 + C++**：Python 以 53% 的出现率断层第一，C++ 是第二硬通货（23%），研究岗还要叠加机器学习与统计功底。

4. **LLM 正在进入量化 JD**（6%），集中在 ML/AI 岗（约一半），传统研究岗尚未普及——是当下卡位的好时机。
5. **学历门槛因岗而异**：PhD 要求约 12%，奥赛/竞赛类硬核要求只在个位数 JD 中出现；研究岗重学历，工程岗重系统能力。
