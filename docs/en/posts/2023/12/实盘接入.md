## Easytrader
Easytrader is a trading agent that executes trades by simulating keyboard and mouse events to control the broker’s desktop client. In this setup, the strategy calls Easytrader’s trading APIs (such as `buy` and `sell`), which Easytrader then translates into mouse-click events on the broker’s GUI to complete the transaction.

The primary advantage is that no formal application or approval is required, and it supports a wide range of brokers (via Tonghuashun/10jqka, excluding Huatai, Haitong, and Guojin). However, because it relies on simulating GUI interactions, it suffers from lower stability and slower response times.

If you must use it for **live trading**, you should dedicate a high-performance physical machine solely for this purpose. Install only the broker’s trading client and Easytrader, running Easytrader in server mode. Your strategy should connect via Easytrader’s remote client. Crucially, do not manually operate this machine to avoid interfering with Easytrader’s automated inputs. Additionally, disable automatic updates and other background processes on this machine.

## Hundsun Ptrade
Ptrade is a quantitative trading platform developed by Hundsun Technologies. Official video tutorials are available for free registration. It is also covered in my course, *Monopoly Quantitative Programming in Practice*.

Ptrade operates on a **broker-hosted model**. Brokers purchase the Ptrade software, customize it, and provide it to their clients. Users develop strategies using Ptrade’s strategy editor. Once backtesting is successful, the strategy is uploaded to run on the broker’s server infrastructure. This integration method provides a Python SDK, allowing orders to be placed via the SDK’s trading APIs.

In hosted mode, internet access is typically restricted, and you cannot update Python or dependent libraries, nor install third-party software. Quantitative strategies become tightly coupled with the broker’s specific trading and data APIs, making switching brokers costly later on. The inability to install custom software limits the use of newer third-party algorithms. If you employ **machine learning** or reinforcement learning, the required libraries may not be available in the broker’s environment, or their versions may differ from your local setup, often without GPU support.

The main advantages are faster market data feeds and the elimination of server maintenance responsibilities.

Ptrade cannot be downloaded publicly; you must open an account with a broker to access it. Live trading usually requires a minimum capital threshold of 300,000 RMB. Currently, you can apply for Ptrade access through brokers such as Guojin, Guosheng, Guoyuan, Anxin, and Dongguan. If you require specific commission rates (e.g., 0.01% with no minimum fee) or lower capital thresholds (as low as 20,000 RMB), please contact me.

## QMT
Xuntou QMT is developed by Beijing Ruizhi Rongke. Like Ptrade, it is a broker-procured and customized solution. However, QMT supports a **local execution mode**, offering better strategy security.

QMT offers two integration methods:
1.  **File-based order scanning**: No restrictions on Python versions or libraries.
2.  **API-based**: Strategies are written and run within the QMT platform, subject to restrictions on Python versions and allowed libraries (though new third-party libraries can sometimes be added via a whitelist).

QMT is not publicly downloadable. You must open an account with a broker to obtain it. Currently, access is available through Guojin, Guosheng, Guoyuan, Anxin, and Dongguan. If you need specific commission adjustments (e.g., 0.01% with no minimum fee) or lower capital thresholds (as low as 20,000 RMB), please contact us using the details at the end of this article.

## East Money EMC
East Money EMC requires a minimum capital threshold of 1 million RMB. You must join their official quantitative technical support group to apply for access. It supports both API trading and local file-based order scanning.

The local file-based order scanning method offers response times under 10ms. It is decoupled from the quantitative program, meaning your strategy can run on any machine, using any Python version and third-party libraries.

However, you are responsible for converting trading instructions (e.g., `buy`, `sell`) into the specific file order format. Similarly, EMC returns order results in CSV format, requiring you to parse them manually.

The `gmadaptor` library provides this encapsulation. Furthermore, it wraps itself as a server, allowing your quantitative strategy to run on different machines and operating systems (since EMC itself is Windows-only).
