## Easytrader
Easytrader is a trading proxy that executes orders by simulating keyboard and mouse events to interact with the broker’s GUI client. In this architecture, the strategy calls Easytrader’s `buy` and `sell` APIs, which Easytrader then translates into mouse-click events on the broker’s trading interface to complete the transaction.

The primary advantage is that no formal application is required to access it, and it supports a wide range of brokers (via Tonghuashun/10jqka), excluding Huatai, Haitong, and Guojin. However, because it relies on simulating GUI interactions, it suffers from poor stability and slow response times.

If you must use Easytrader for **live trading**, you should dedicate a high-performance physical machine solely for this purpose. Install only the broker’s trading client and Easytrader, running Easytrader in server mode. Your strategy should connect to this machine via Easytrader’s remote client. Crucially, do not manually operate this machine to avoid interfering with Easytrader’s automated actions. Additionally, disable automatic updates and other background processes on that machine.

## Hundsun Ptrade
Ptrade is a quantitative trading platform developed by Hundsun Technologies. An official video tutorial is available for free registration. It is also covered in my course, *Big Fortune Quantitative Programming in Practice*.

Ptrade operates on a broker-hosted model. Brokers purchase the Ptrade software, customize it, and provide it to their clients. Users develop strategies using Ptrade’s editor, pass the **backtest**, and then deploy them to the broker’s server room. This integration method provides a Python SDK, allowing order placement through the SDK’s trading APIs.

In hosted mode, internet access is typically restricted, and you cannot update Python or its dependency libraries, nor install third-party software. Quantitative strategies are tightly coupled with the broker’s trading and data APIs, making switching brokers costly later on. Since you cannot install custom software or libraries, leveraging newer third-party algorithms is difficult. If you employ **machine learning** or reinforcement learning, the required libraries may not be available in the broker’s environment, or their versions may differ from your local setup, often without GPU support.

The main advantage is faster market data feeds and the elimination of server maintenance responsibilities.

Ptrade is not publicly downloadable; you must open an account with a broker to obtain it. Live trading access generally requires a minimum capital threshold of 300,000 RMB. Currently, you can apply for Ptrade access through brokers such as Guojin, Guosheng, Guoyuan, Anxin, and Dongguan. If you need specific commission rates (e.g., 0.01% with no minimum fee) or lower capital thresholds (as low as 20,000 RMB), please contact me.

## QMT
QMT (Xintou QMT) is developed by Beijing Ruizhi Rongke. Like Ptrade, it is purchased and customized by brokers for their clients. However, QMT supports a local execution mode, offering better strategy security.

QMT offers two integration methods: file-based order scanning and API-based execution. The API method requires writing and running strategies within the QMT platform, imposing restrictions on Python versions and available libraries (though third-party libraries can be added via a whitelist).

The file-based scanning mode has no such restrictions.

QMT is not publicly downloadable; you must open an account with a broker to access it. Currently, you can apply for QMT access through brokers such as Guojin, Guosheng, Guoyuan, Anxin, and Dongguan. If you need specific commission rates (e.g., 0.01% with no minimum fee) or lower capital thresholds (as low as 20,000 RMB), please contact us. Contact details are provided at the end of this article.

## East Money EMC
East Money EMC has a minimum capital threshold of 1 million RMB. Access requires joining their official quantitative technical support group to apply. It provides both API-based trading and local file-based order scanning.

The local file-based scanning mode offers response times under 10ms. It is decoupled from the quantitative program, allowing the strategy to run on any machine with any Python version and third-party libraries.

However, users must manually convert trading instructions (e.g., `buy`, `sell`) into the required file order format. EMC also returns order results in CSV format, requiring users to parse them themselves.

`gmadaptor` provides a wrapper for this functionality. Furthermore, it encapsulates itself as a server, allowing quantitative strategies to run on different machines and operating systems (since EMC itself only runs on Windows).
