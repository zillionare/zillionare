## V. Key Takeaways

1. **The Entry Trio = Python + Statistics/Probability + C++**: Python leads with a 53% appearance rate, while C++ is the second most essential currency (23%). Research roles additionally demand machine learning and statistical foundations.
2. **Engineering is the Largest Entry Point**: Software engineering roles dominate this quarter. Low-latency/HFT is explicitly required in 17% of JDs (microsecond-level systems and C++ performance optimization are core testing points).
3. **Niche High-Value Skills**: System trading skills such as KDB+/q, DPDK/kernel bypass, and FIX protocol appear in single-digit JDs across the board. These represent scarce capabilities where "few know them, but many urgently need them."
4. **LLMs Are Entering Quant JDs** (6%), concentrated in ML/AI roles (about half), but not yet widespread in traditional research roles—this is an opportune moment to position yourself.
5. **Educational Thresholds Vary by Role**: PhD requirements stand at approximately 12%, while Olympiad/competition-based hard requirements appear only in single-digit JDs. Research roles prioritize academic credentials, while engineering roles prioritize system capabilities.
