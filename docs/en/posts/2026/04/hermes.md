After using OpenClaw extensively, I was eager to try Hermes Agent. After a day of testing, I can conclude that it’s difficult to declare a winner between OpenClaw and Hermes, as both are iterating rapidly, with significant improvements appearing every few days.

However, both are clearly excellent and worth using.

That said, my experience with OpenClaw earlier was marred by installation and maintenance friction, feeling more like driving a manual car. I recall having to switch Node.js versions, configure npm mirrors, and install Bun, among other steps.

Hermes Agent, by contrast, is nearly self-contained regarding dependencies. In fact, it has more dependencies—requiring both Node.js and Python—but bundles them all together. This means you can install from a single package without needing to access the network during the process.

Of course, since the package is hosted on GitHub, access speed and stability are still somewhat limited.

This article is not a benchmark test. Instead, it shares my journey from a "zero-frame start" after installing Hermes Agent to enabling it to perform useful tasks.

## First Installation Failed

My first attempt to install Hermes failed. I only discovered the cause by checking the logs: I had entered the API key incorrectly. Hermes seems to lack a validation step for the model at this stage. If the API key is correct, it lists available models; if incorrect, it provides insufficient prompts and allows you to proceed with the setup, ultimately leading to installation failure.

I used version 0.8.0, released five days ago. By the time you read this, this behavior may have changed slightly.

I chose the quick installation mode. In this mode, you only need to provide the large language model (LLM) configuration and communication channel settings. For the rest of the installation, I chose to instruct the Agent via WeChat.

I believe this is the correct way to use an Agent.

!!! tip
    After installing Hermes Agent, I roughly understood why they built this product. The first model recommended in the list is their own. Although tokens are currently in high demand, in the long run, there may be an oversupply. 90% of users might find that tokens generated by Claude Opus 4.6 are sufficient, making it unnecessary to consume more advanced tokens.

## Self-Evolution

Next, I observed its self-evolution capabilities.

My first feedback was to have it report progress periodically. Since the setup was just starting, I was worried it might not be "alive."

![Requesting Hermes to periodically report task progress](https://cdn.jsdelivr.net/gh/zillionare/imgbed2@main/images/2026/04/20260413183633.png)

The issue that arose was that the reports were too long, so I gave it an instruction:

> [!quote]
> Eve, when reporting progress, be concise. Use `task check` format. If completed, use ✅. If execution stalls, place ⚠️. Do not send help information or next-step task suggestions at this time.

> Let Muse start collecting materials on this topic, preparing core viewpoints and data. Will the comprehensive implementation of after-hours fixed-price trading in China A-shares have a significant impact? What impact will it have on quantitative trading?

The first report format was messy, so I gave another instruction:

> [!quote]

![Hermes’ output after improving its scheduled progress reports](https://cdn.jsdelivr.net/gh/zillionare/imgbed2@main/images/2026/04/20260413183934.png)
