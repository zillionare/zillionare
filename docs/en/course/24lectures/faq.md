## Other Questions

!!! tip "I have a GPU. Can I use it in quantitative trading?"
    If you start directly with price data, end-to-end AI techniques are not yet mature and may never be. Price data contains significant noise, or rather, it is a many-to-many mapping, making effective learning difficult.<br><br>
    The most mature approach to combining quantitative strategies with AI today involves manually extracting factors and using machine learning, particularly algorithms like XGBoost or LightGBM, for factor combination. Both XGBoost and LightGBM can partially utilize GPUs, though using a GPU is not mandatory. Especially since LightGBM’s training speed is already very fast.
