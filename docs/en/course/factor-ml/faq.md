## Enrollment Process and Learning Environment

!!! abstract "How do I take the course?"
    The course consists entirely of pre-recorded videos uploaded to Lizhi Weike.

    Course materials are provided as Jupyter Notebooks, hosted on our dedicated servers. After purchasing the course, we will assign you an account and create a personalized computing environment. Within this environment, you can read and run the provided Notebooks, and you can also create your own. Each student has an independent runtime environment, ensuring that your Notebooks remain private and inaccessible to others.

    To purchase, please click [here](https://weike.fm/xw1UD19dca).

!!! abstract "How long does it take to complete this course?"
    The duration depends entirely on your schedule. If you complete one lesson per day, you should be able to finish the course within three weeks.

    Video lectures are available for free indefinitely. Your exclusive courseware server access is valid for 6 months. After this period, you can still log in for up to two years, but you will be moved to a shared server. Please note that the courseware server is intended solely for learning purposes and cannot be used as a general-purpose cloud server.

!!! abstract "Who is this course for / What are the prerequisites?"
    Please refer to the prerequisites listed in the [Course Introduction](/articles/course/factor-ml/intro/).

!!! abstract "Do you provide a learning environment?"
    Yes. We provide a server cluster equipped with 192 CPU cores and 256GB of RAM for students. By logging in via a web browser, you can study online and run our example code. This environment includes daily market data specifically prepared for factor analysis. For other data sources, students can obtain access through our premium Tushare accounts.

!!! abstract "What are the advantages of your learning environment? Can I set up my own?"
    Our course examples use specialized data interfaces. To set up a local environment, you would need to modify these interfaces to provide your own data. These interfaces are straightforward and come with detailed tutorials.

!!! abstract "Can I download the course data for local use?"
    The data used in the course environment is **procured** from third parties under agreements that prohibit distribution and resale. Therefore, we cannot guarantee the availability of data downloads.

!!! abstract "I want to learn more about the course"
    We offer a course preview environment containing selected lessons (videos, Notebooks, and exercises). Please add our teaching assistant on WeChat (ID: quantfans_99) to obtain the access link.
