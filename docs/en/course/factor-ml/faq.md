## Enrollment Process and Learning Environment

!!! abstract "How do I take the course?"
    The course consists of video lectures, Jupyter Notebook materials, and Q&A sessions. All video lectures have been pre-recorded and uploaded to Lizhi Weike.

    The course comprises 21 lessons, totaling 22 hours of video content.

    Course materials are provided as Jupyter Notebook documents, hosted on our servers. After purchasing the course, we will assign you an account and create a dedicated computing environment. Within this environment, you can read and execute the provided Notebooks, as well as create your own.

    Data and dependency libraries are pre-configured in this environment. Code can be executed directly, and you are free to modify and debug it.

!!! abstract "How long does it take to complete the course?"
    This depends primarily on your own schedule. If you complete one lesson per day, you should be able to finish within three weeks.<br><br>
    Video lectures are available for free viewing permanently. The dedicated courseware server is available for 8 months.<br><br>The courseware server is for learning purposes only and cannot be used as a general-purpose cloud server.

!!! abstract "Who is this course for / What are the prerequisites?"
    Please refer to the prerequisites in the [Course Introduction](/articles/course/factor-ml/intro/).

!!! abstract "Do you provide a learning environment?"
    We provide a server cluster with 192 CPU cores and 256GB of RAM for students. By logging in via a browser, you can learn online and run our example code. This environment provides daily market data for factor analysis. For other data, you can obtain it through the high-tier Tushare account we have purchased for you.

!!! abstract "What are the advantages of your learning environment? Can I set up my own?"
    Our course examples use specialized data interfaces. If you set up your own environment locally, you would need to modify these interfaces to provide your own data. These interfaces are simple and come with detailed tutorials.

!!! abstract "Can I download the course data for local use?"
    The data used in the course environment is **procured** from third parties and, per agreement, cannot be distributed or resold. Therefore, we cannot guarantee data downloads.

!!! abstract "I want to learn more about the course"
    We offer a course preview environment containing selected lessons (videos, Notebooks, and exercises). You can add the teaching assistant’s WeChat (quantfans_99) to obtain the link.
