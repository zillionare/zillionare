## Enrollment Process and Learning Environment

!!! abstract "How do I take the course?"
    The course consists of video lectures, Jupyter Notebook materials, and Q&A sessions. All video lectures are pre-recorded and hosted on Lizhi Weike.

    The course comprises 21 lessons, totaling 22 hours of video content.

    Course materials are provided as Jupyter Notebook documents, hosted on our server. After purchasing the course, we will assign you an account and create a dedicated computing environment for you. Within this environment, you can read and run the provided Notebooks, as well as create your own.

    Data and dependency libraries are pre-configured in this environment. Code can be executed directly, and you are free to modify and debug it.

!!! abstract "What is the course price?"
    The current price is 3,599 RMB. Before purchasing, we recommend adding the teaching assistant’s WeChat (quantfans_99) to understand the purchase process, obtain discounted pricing, and receive gift items.

!!! abstract "How long does it take to complete the course?"
    This depends primarily on your own schedule. If you complete one lesson per day, you should finish within three weeks.<br><br>
    Video lectures are available for free viewing permanently. The dedicated course server is available for 8 months.<br><br>The course server is for learning purposes only and cannot be used as a general-purpose cloud server.

!!! abstract "Who is this course for / What are the prerequisites?"
    Please refer to the prerequisites outlined in the [Course Introduction](/articles/course/factor-ml/intro/).

!!! abstract "Do you provide a learning environment?"
    We provide a server cluster with 192 CPU cores and 256GB of RAM for students. By logging in via a browser, you can learn online and run our example code. This environment provides daily market data suitable for factor analysis. For other data, you can use our high-tier Tushare account.

!!! abstract "What are the advantages of your learning environment? Can I set up my own?"
    Our course examples use specialized data interfaces. To set up the environment locally, you would need to modify these interfaces and provide your own data. These interfaces are straightforward and come with detailed tutorials.

!!! abstract "Can I download the course data for local use?"
    The data used in the course environment is **procured** from third parties, and distribution or resale is prohibited under our agreement. Therefore, we cannot guarantee data downloads.

!!! abstract "I want to learn more about the course"
    We offer a course preview environment containing some lessons (videos, Notebooks, and exercises). Add the teaching assistant’s WeChat (quantfans_99) to obtain the link.
